# UX/UI 案（画面モックアップ）

`mockups/` は、実装前に描いた画面の静的モックアップです（HTML。デザインキャンバスからの書き出し）。
画面は **5つ**（決定記録 0003）: PC はボード／業務の見直し／設定、スマホは自分の予定／業務詳細。
下の表は、その5画面を状態ごとに描き分けたものです。画面仕様の正本は `docs/screens.md` で、モックアップは見た目の参考です。

| ファイル | 画面（状態） | 端末 |
|---|---|---|
| Main.dc.html | ボード — 時間割に人を付ける | PC・タブレット |
| Morning.dc.html | ボード（その日が空のとき）— 今日の時間割を作る（先週の番で並べ、1タップで作る） | PC |
| StaffView.dc.html | ボードの職員表示 — 重なり・誰もいない時間帯（印刷で分担表） | PC |
| Panel.dc.html | ボードの担当を追加パネル — 問題なしの人だけを出し、他は畳む | PC（スマホはシート） |
| Review.dc.html | 業務の見直し（今週）— 区分と時間帯、ノンコアの枠 | PC |
| Setup.dc.html | 設定 — はじめて（2択）／ふだん（施設コード・表示名・初回の警告・名簿の貼り付け） | PC |
| Phone-Mine.dc.html | 自分の予定（リーダー）— いま・つぎ・きょうの流れ、［自分｜全体］ | スマホ |
| Phone-FirstTimer.dc.html | 自分の予定（初回の応援・勤務前）— 最初の予定をお願いすること・物品ごと先頭に | スマホ |
| Phone-Detail.dc.html | 業務詳細 — お願いすること／しないこと、物品、手順、対象の方、困ったら | スマホ |
| Phone-All.dc.html | 全体（リーダー）— 各行に ⋯ と ＋、画面下にクイック操作と元に戻す | スマホ |
| Phone-Escort.dc.html | 付き添い・外出（2タップ目）— 既定値入りのプレビューと「この内容で決定」 | スマホ |

モックアップ内の `<x-dc>` 等はキャンバス用の要素で、ブラウザで直接開いても中身は表示されます。
利用者・職員はすべて架空です。
