# UX/UI 案（画面モックアップ）

`mockups/` は、実装前に描いた 9 画面の静的モックアップです（HTML。デザインキャンバスからの書き出し）。
画面仕様の正本は `docs/screens.md` で、モックアップはその見た目の参考です。

| ファイル | 画面 | 端末 |
|---|---|---|
| Main.dc.html | ボード — 時間割と配置 | PC・タブレット |
| StaffView.dc.html | 職員ビュー — 重なり・偏り・誰もいない時間帯（印刷で分担表） | PC |
| Morning.dc.html | 朝の流れ — 出勤者に役割を付けて、型を当てる | PC |
| Candidates.dc.html | 担当を追加 — 候補と理由（問題なし／注意／勤務外・休み） | パネル |
| Review.dc.html | 見直し — 区分×時間帯、ノンコアの枠（週） | PC |
| Setup.dc.html | はじめの設定 — サンプルで試す／自分の施設 | PC |
| MyNavi.dc.html | マイナビ — いま・つぎ・きょう | スマホ |
| MyNaviDetail.dc.html | 業務詳細 — 初回の方が段取りで迷わない | スマホ |
| LeaderPhone.dc.html | リーダーのスマホ — きょうの全体とクイック操作のプレビュー | スマホ |

モックアップ内の `<x-dc>` 等はキャンバス用の要素で、ブラウザで直接開いても中身は表示されます。
利用者・職員はすべて架空です。
