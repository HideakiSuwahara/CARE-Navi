# グリル: 素人の審査員の最初の 10 分

状態: 改修可
日付: 2026-11-06
出どころ: 作者の依頼「素人の審査員の目線で巡回」。ux-first-timer（審査員 1 人のペルソナ、PC 1440・Pixel 7、`/` から）と demo-director（README・提出文・動画の筋・最初の画面）の報告。

## 審査員が画面から受け取った価値（7〜8 分で）

「介護施設の一日の仕事を時間割にして、空いている人を理由つきで当て、欠勤があっても数タップで組み直せる。初日の人もスマホで、いま何を・どこで・誰に相談すればいいか分かる道具」。ただし最初の 3 分では「シフトのガントチャート」止まり。いちばん伝わるのはスマホの「自分の予定」だが、入口から見えない。

伝わらなかったこと: 介護記録ではなく業務のナビゲーション／製品内で AI を使わない・判断は人／変更は 10 秒以内／「仕事に、人を付ける。」の意味。どれも画面に言葉が無い。

## 直したもの（不具合。グリルの外）

- トップの「サンプル施設で試す」から入って設定を開くと「はじめに」に戻り、データが消えたように見えた → ボード・自分の予定を開いたら印を付ける（af59d79）。

## 案 1: サンプルの時刻
- 困りごと: サンプルの日付は 11/3 固定なのに、時刻は端末の実時刻。審査員が夜や朝に開くと、現在時刻の線が出ず 6:00 から表示され、「担当あと1人」（入浴 10:30）も見えない。「更新 21:00」も意味が分からない。
- 案: サンプル施設のときは、開いた瞬間を 10:12 として時計が進む（現在時刻の線も進む）。日付の横に「サンプル施設の一日」と書く。

## 案 2: 最初の画面（/）に「何の道具か」と 3 つの場面
- 困りごと: 説明 1 段落とボタン 2 つで、画面の 8 割が空白。誰の何が楽になるか分からない。
- 案: ボタンの下に 3 つの場面を 1 行ずつ（朝: 1 タップで時間割／途中: 欠勤も 3 タップで組み直す／初日の人: スマホでいま何を・どこで・誰に相談か）。それぞれリンク（3 つ目は `/me` の初回の人へ）。下に「しないこと」1 行（介護記録ではない・配置を決めるのは人・製品の中で AI を使わない）。

## 案 3: サンプルデータ
- 困りごと: (a) 入浴介助（担当あと1人）の「＋」を開くと空いている人が 0 人で、誰を付けても注意が出る。審査員が「この人でいいのか」で止まる。(b) 次の日の「この内容で作る」の直後に「担当未定 34件」。夜勤の明けを休みにして今夜の夜勤が空になり、「壊れた」に見える。
- 案: (a) 入浴の時間に空いていて入浴担当可の人をちょうど 1 人に（休憩の時刻など、現場として自然な直しで。人数は盛らない）。(b) 次の日以降にも勤務表（夜勤を含む）を入れておく。

## 案 4: スマホの名前を選ぶ画面
- 困りごと: どれがリーダーか、どれが初日の人か分からず、リーダーの［全体］にもたどり着けない。
- 案: 名前の横に「リーダー」の札（「初回」と同じ形）。サンプル施設のときだけ「試すなら: 加藤（初日の人）／佐藤（リーダー）」の 1 行。

## 案 5: 使い方・業務の見直しの最初の一文
- 困りごと: 使い方は現場の FAQ で、道具の説明が無い。業務の見直しは「コア／ノンコア・延べ時間・介護助手の勤務帯」が分からない。
- 案: 使い方の先頭に「ケアナビとは」3 行と「はじめて触る方へ: 3 つの操作」。業務の見直しの見出しの下に「介護の資格が要らない仕事（配膳準備・洗濯など）が、どの時間帯に寄っているかを見る図です」。

## 案 6: 文書（README 冒頭・提出文・動画の筋）
- 困りごと: README 冒頭が写真の表で、公開 URL・3 操作・作らないものが無い。提出文の数字（ループ 8 回・決定記録 10 本）が古い。動画の筋に実装に無い操作（「ずらす」）・撮れない場面（空いている人を選ぶ）・頻度の断定がある。
- 案: README 冒頭 8 行（何の道具か／公開 URL→サンプル／3 操作／作らないもの／AI の境界／同期はデモ）。提出文の数字を出し直す。動画の筋を実装とデータに合わせる。

## そのほか（小さな直し。グリルの結論で一緒に扱う）
- PC とスマホで「担当未定」の数が違う（PC 3 件・スマホの全体 1 件）→ 数え方をそろえるか、「これからの担当未定」と文字で分ける。
- 付き添い・外出の既定が夜間に「翌4:15」になる → 夜間は翌 9:00 を既定に。
- ⓘ で説明が帯に差し込まれ札が折れる、［利用者ごと］で開いた時点に空白の格子、スマホの全体で「担当: なし／まだいません」が混在。

- サンプル施設のときだけ、?now が無ければ時計は開いた瞬間を 10:12 として進む。日付の横は「サンプル施設の一日」、「更新」は出さない。
- / に 3 つの場面（朝 1 タップ／途中 3 タップ／初日の人のスマホ）とリンク、「しないこと」1 行。スマホの名前一覧はサンプルのときだけ「試すなら」とリーダーの札。
- 使い方の先頭に「ケアナビとは」、業務の見直しに 1 文。
- サンプルデータ: 入浴介助に空いている入浴担当可の人を 1 人（休憩の時刻などの自然な直し）、次の日以降の勤務表（夜勤を含む）。現場役のレビューを通す。
- README 冒頭・提出文・動画の筋を書き直す。

- サンプルで ?now なしに開くと 10:12 の線が出て、時間とともに進む（E2E: 時計をずらして確かめる）。
