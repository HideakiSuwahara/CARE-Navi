## 運用の注意

- 改善案はグリルしてから（`grill-gate`）。`docs/grills/` に「状態: グリル待ち」があると `src/` の編集はフックで止まる。
- E2E は開発サーバー（localhost:3000）に向けて走る。`next build` を開発サーバーと同時に走らせると `.next` が壊れて全件落ちる。そのときは開発サーバーを止めて `.next` を消し、立ち上げ直す。
- コミットの末尾の署名は、そのセッションの system の指示に従う。
