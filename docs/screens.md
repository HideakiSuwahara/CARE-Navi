# 画面仕様

画面は **6つ**（決定記録 0003・0004）。PC: ボード／利用者／業務の見直し／設定。スマホ: 自分の予定／業務詳細。
文言は docs/wording.md、チェックは docs/checks.md、データは docs/data-model.md を参照。

## 0. 共通の規則

### 0.1 シンプルにするための約束
- **1画面1目的。** その画面で一番多い操作を、一番大きなボタンにする。
- **既定値を入れておく。** 人が選ぶのは「違うところ」だけ。
- **押す回数**: 朝の準備 1、担当の追加 2（D&D なら 1）、スマホの変更 3 以内、元に戻す 1。
- **人に数字を付けない。** 件数・予定時間を職員の名前の横に出さない。
- 仕組みの言葉（一括・共通・コア・ノンコア・役割枠・型）を職員の画面に出さない。画面の呼び方は §0.9。

### 0.2 見た目
- 書体: Noto Sans JP。PC 本文 15px、スマホ本文 16px・補足 14px。カード見出し 15px 太字。
- 地色 `#F3F3EF`、面 `#FFFFFF`、罫 `#E3E3DE`、文字 `#1C1F23`、補足文字 `#5B6168`、主色 `#1D5C8A`。
- 状態は**文字**で示し、色は補助。色で区別するものは明度も変える。
- 押せる領域は 44×44px 以上（PC も同じ）。
- アイコンは線画の SVG のみ。絵文字は使わない。
- 現在時刻ライン: `#C2410C` 2px と時刻タグ。1分ごとに進む。

### 0.3 業務カード（ボード）
| 要素 | 表示 |
|---|---|
| 業務名 | 太字。個別なら「排泄介助 田中様」 |
| 時刻 | `10:30–12:00`（翌日分は `翌2:00`） |
| 対象 | 一括は「20人」（押すと対象者一覧）。個別は名前に含める。対象なしは何も出さない |
| 担当 | 名字のチップ（`button`。キーボードで持てる）。初回の人は「加藤 初回」 |
| 充足バッジ | §0.4。未充足のときだけ |
| 「＋」 | すべてのカードに常に出す（44px） |
| 休憩 | 薄い紫地・破線枠。**バッジなし** |
| 中止 | 取り消し線と「中止」。カードは残す |
| 終わった | 人が付けた印（決定記録 0010）。2 行目に「✓ 終わった」、文字は薄く（1 行のカードは ✓ だけ）。時刻が過ぎただけの枠は通常の濃さのまま（終わりの時刻から 15 分で `data-unfinished`。休憩・見守りは対象外） |
カードを押すと詳細パネル（場所・対象者・担当・手順・相談先、操作: 担当を追加／中止／ずらす）。区分名・場所・必要人数・条件はカードに出さず、詳細に出す。

### 0.4 充足バッジ（必要人数 n、割当 a。休憩カードには付けない）
| 状態 | 文言 | 見た目 |
|---|---|---|
| a = 0 | **担当未定** | 橙系地 `#FFE7D6`・文字 `#8A3B00`、カード枠 `#B5651D` 破線 |
| 0 < a < n | **担当あと {n−a} 人** | 黄系地 `#FFF3C4`・文字 `#6B4E00`、カード枠 `#B5651D` |
| a ≥ n | （無印） | |
「担当未定」「担当あと n 人」は予定の担当枠の差分で、ケアの未実施人数ではない。この注記はボードのツールバーに1回だけ（ⓘ）。

### 0.5 担当の追加（パネル）
- PC はボード右のパネル、スマホは下から出るシート。見出しに業務名・時刻・バッジ。
- **「問題なし」の人だけを開いて出す**（各行: 名字・番・理由一文・「追加」）。
- その下に「ほかの人（注意 3・勤務外 3）」を1行。押すと開く。注意の人は理由つきで追加できる。勤務外・休みの人は「追加」を出さない。
- 「追加」1回で決まる（確認なし）。結果はトーストと「元に戻す」。

### 0.6 プレビュー → 決定
クイック操作は、**こう変わります** の一覧を見せてから「この内容で決定（元に戻せます）」。
- 行: `追加` `外す` `中止` `ずらす` と、結果として出る `担当未定` / `担当あと n 人`。外したくない行はチェックを外す。
- 休憩と重なるときの既定は **休憩を後ろへずらす**（外さない）。
- 決定は1つの batchId。元に戻すと全行が戻る。

### 0.7 元に戻す
- 操作直後、画面下中央にトースト「山本さんを 入浴介助 10:30 に入れました ［元に戻す］」（8秒）。
- トーストが消えても、PC はツールバー、スマホは画面下に「元に戻す」を常に出す（直前の操作名つき）。10手まで。

### 0.8 更新時刻・表示名・空状態
- ボードと全体の右上に「更新 10:07」（時刻のみ）。同期の端末では、つながっていれば「同期中」、届かないときは「この端末の内容（未送信 n 件）」、つなぐ前は「つないでいます」。自分の予定には、届かないときだけ「この端末の内容」を出す。
- 利用者名: ボード（施設PC）はフルネーム。スマホは設定に従う（既定「203 田中様」）。
- 空状態は「次にすること」を1文と1ボタン。エラーは理由と次の手。

### 0.9 画面の呼び方
| 仕組み | 画面の言葉 |
|---|---|
| 一日の型 | 業務表 |
| 役割枠 | 番（早番A、日勤B、介護助手…） |
| 型を当てる | 業務表から作る（ボタン「今日の時間割を作る」） |
| マイナビ | 自分の予定 |
| 見直し | 業務の見直し |
| 適用 | この内容で決定 |

## 1. ボード（PC・タブレット）

**目的**: 今日の業務に人を付ける。担当未定を埋める。

**上部バー（1段）**: 「ケアナビ」施設名 ／ ナビ［ボード｜業務の見直し｜設定］ ／ 日付「‹ 前の日」11月5日（木）「次の日 ›」（今日でない日は「今日へ」）／ 更新 10:07。開く日は、自分の施設は端末の今日（6:00 より前は前の日の業務日）、サンプル施設は基準日 11/3（決定記録 0013）。

**ツールバー（1段）**: ［グループ｜職員］の切替 ／ 「担当未定 2件」「担当あと○人 1件」「終わっていない 2件」（押すと該当カードへ順に移動し強調。印や担当が変わったら先頭から。終わっていない＝終わりの時刻から 15 分過ぎて印の無い枠。休憩・見守りは除く。担当未定とは別に数える。決定記録 0010） ⓘ（担当未定と終わっていないの両方を一文ずつ） ／ 「欠勤・早退」「付き添い・外出」（スマホの全体と同じ流れ。詰所の PC で電話を受けたとき用。決定記録 0014） ／ 右端に「元に戻す（直前の操作名）」と「⋯」メニュー（分担表を印刷・今日を業務表として保存・サンプルに戻す）。

**時間割**: 縦＝時間（1時間ごとの罫、1分=2px）、横＝グループ（東フロア／さくらユニット／共通）。開いたとき現在時刻へ自動で寄せる。06:00 から翌 6:00 まで上下にスクロール（翌 6:00 より後に終わる業務があれば、1 時間単位でそこまで伸ばし、「ここから翌朝 6:00 以降（夜勤明け）」の破線を引く）。重なるカードは横に並べる（長い見守りは左）。

**右パレット「きょうの出勤者」**: 名字・番・勤務時間。勤務前の人は灰色「11:00から」。初回の人は「初回」。その下に「＋ 今日来る人を足す」（名前と番 →「この内容で決定」。その番の業務で担当が足りない枠に入る。グリル U2）。下に「休み」: 名字と「この人の番の枠 2件が担当未定」。**件数・予定時間は出さない。**

**操作**
- 職員チップをカードへドラッグ → 割当（1操作）。カードからカードへ → 移動。パレットへ戻す → 外す。
- カードの「＋」 → パネル → 「追加」（2操作）。
- カードを押す → 詳細パネル（中止・ずらす −30/+30/時刻入力・担当を外す・対象者）。

**その日の時間割が空のとき**（朝）: 時間割の上に帯「**今日の時間割を作る**」。
- 先週の同じ曜日の番で出勤者が並び、曜日の業務表（火・金は入浴日）が選ばれている。
- 先週の分がない（使い始めの週）ときは、6 日前までのいちばん近い日と同じ番で並ぶ。前の日に夜勤だった人は明けなので休み（決定記録 0013）。どの日もないときは「はじめての日」で全員を休みで並べる。
- 名前の横の番は押すと選べる。休みは「休み」。応援は「＋ 応援の人」。
- 「**この内容で作る**」1回で時間割ができる → 「担当未定 2件・担当あと1人 1件」と表示し、該当カードへ寄せる。トーストで元に戻せる。

**職員表示**（横軸＝職員）: 縦＝職員（名字・番・勤務時間）、横＝時間。担当を帯で描く。勤務外は斜線。休憩は点線の帯。重なりは二重枠と「重なり」の文字。最下段に「見守り」のつながり（空きは「13:00–14:00 担当未定」）。印刷すると分担表（A4横）。

**スマホ幅**: ボードは出さず「自分の予定」の［全体］を案内する。

## 1A. 利用者（PC）— 施設の日課と24時間シート（決定記録 0004）

> 0015: 右上に「1 人ずつ足す・直す」（名前・グループ・部屋。「直す方を選ぶ」でその方の欄。退所はここ。一文の確認のあと、今日以降の枠の対象から外れ、過去は履歴として残る。元に戻すと対象にも戻り、「戻しました」と出る。入院など戻る方は外さないと書く）。まとめて入れるのは「名簿を貼り付ける」。

**目的**: 利用者ごとの生活の流れを持ち、それを時間割の業務にする。初期値は「全員が標準どおり」で、違うところだけ直す。

**上部**: ［一覧｜24時間シート］の切替、グループの切替（東フロア／さくらユニット）、右に「名簿を貼り付ける」「CSV」。その上に見出し「利用者の日課」と1文「施設の日課と、方ごとの時刻・サポートを決めます。次に時間割を作るときから入ります。」。一覧は列の上に［すべて｜朝｜昼｜夜］（朝 5:00–11:00、昼 11:00–17:00、夜 17:00–翌5:00）。

**一覧**（従来型向け・まとめて作る）
- 縦に利用者（部屋・名前）、横にそのグループの日課（名前と標準の時刻）。
- マス: 標準どおりは薄い「—」、時刻の変更は太字の時刻、なしは「なし」。
- マスを押す → 小さなパネル（開始時刻、「この方はなし」、「標準に戻す」、「この内容で決定」）。
- 行の先頭のチェックで複数を選び、列の見出しの「まとめて変える」で同じ時刻・なしを一度に（1回で元に戻せる）。
- 「＋ 日課を足す」: 業務の種類・開始・終わり・必要人数 →「この内容で決定」。そのグループのすべての業務表に入り、全員が標準どおり（決定記録 0013）。今日の時間割がもうあれば「今日（11/5）の時間割にも入れる」（既定で入れる）。
- 列の見出しの「標準 5:00–6:00」を押す → 標準の時刻・必要人数を変える／「この日課を外す」（確かめてから）。どれも 1 回で元に戻せ、次に時間割を作るときから入る。

**24時間シート**（ユニット型向け・一人ずつ）
- 左に利用者の一覧、右に表。列: 時刻｜生活の流れ｜生活リズム｜意向・好み｜自分でできること｜サポートが必要なこと。
- 行の状態を文字で示す: 「標準」「変更」「この方はなし」「この方だけ」。
- 4つの項目はその場で書け、フォーカスが外れたら保存。
- 「＋ この方だけの行を足す」（時刻、名前、業務の種類〔任意。選ぶと時間割に枠ができる〕）。
- 書き出し: 「印刷」（A4 縦。利用者名・部屋・グループ・更新日と表）、「CSV」（UTF-8 BOM つき、Excel で開ける）。

**時間割への入り方**（0004 §2）: 標準どおり → 一括の枠／枠の中に変えた方 → 一括の枠のまま（対象者一覧に時刻）／枠の外 → 別の枠（同じ時刻はまとめる）／なし → 入れない。

## 2. 業務の見直し（PC、週）

**目的**: ノンコアの枠を、介護助手等の勤務帯とあわせて見直す。

- 前提を常時表示: 「予定時間ベース（実施時間ではありません）」「配置を見直すための数字です。職員の評価には使いません」。
- 期間は「今週」のみ。
- 左「区分 × 時間帯」: 時計の1時間ごと（6:00 から 24 本）の積み上げ棒。コア＝塗り、ノンコア＝斜線、休憩・中止は含めない。背後に介護助手等の勤務帯（番の印 `reviewBand`）。下に同じ数値の表。
- 右「ノンコアの枠」: 業務・時刻・曜日（7日なら「毎日」）・番・介護助手等の勤務帯の［中｜外］・今週の予定時間。判断の言葉（任せられる・要らない）は書かない。
- 単位は延べ時間（長さ × 必要人数 × 7日）。表に「1日あたり」。区分「その他」は点の模様。数字の出し方は決定記録 0008（時間割ができている日はその日の予定、ほかの日は曜日の業務表）。「見直す ▾」の操作は作らない（0004 §8）。

## 3. 設定（PC）

**はじめて開いたとき**: 2つのボタンだけ。「**サンプル施設で試す**」（押すとボード）／「自分の施設で始める」。

**自分の施設で始める**（1画面、上から順に）:
1. 施設の名前、グループ（1行1つ）。
2. 利用者を貼り付け（名前, グループ, 部屋）。
3. 職員を貼り付け（名前, 職種, 担当条件[任意], PHS[任意]）。
4. 「登録する」→ 業務の種類（約20種）と業務表（従来型／ユニット）が入った状態でボードへ。

**追加・変更**（決定記録 0016）: 施設の名前 ／ グループ（ユニット・フロア: 一覧に種類と所属の人数。名前を変える・外す（所属が残る間は外せない）・「＋ グループを足す」＝雛形の同じ種類の番と日課の枠を写し、次の日の時間割から出る）／ 番（一覧に名前・時刻・グループ・リーダーの順・使われている勤務表の日数と業務表。名前を押して直す、「＋ 番を足す」。時刻を変えても入れてある勤務表は変えない。今日以降の勤務表か業務表で使われている番は外せない）／ 職員 ／ 名簿の貼り付け ／ 月の勤務表 ／ 「ほかの画面で直すもの」（利用者・日課 → 利用者の画面、業務表 → ボードの ⋯、その日の番 → 朝の帯）。

**ふだんの設定**: 施設コード ／ 手元画面の利用者名［フルネーム｜部屋番号＋姓｜部屋番号］／ 初回の方の警告［する｜しない］／ **職員**（名前を押すとその人の欄: 名前・職種・PHS・退職。「＋ 1 人ずつ足す」は同じ欄に担当条件の □／✓ が付く。退職は一文の確認のあと（押すのは最後に出た日の翌日と案内）、今日以降の担当と出勤を一緒に外し、外れた枠は「担当未定」か「担当あと n 人」になる。同じ姓が 2 人いれば名を添える。一覧に PHS も出す。元に戻せる。決定記録 0015）。右の担当条件は、職員ごとに、業務の種類が条件にしているもの（入浴担当可・看護師）を「□／✓」で付け外し。1 タップ、元に戻せる。業務が条件にしていないもの（介護福祉士など）は「ほかの条件」として下に分け、候補の理由には出ないと書く。「ほかの条件を足す」は名簿の印として残るだけ。等級・評価ではない: 条件を満たさない人も「注意」の理由つきで担当にできる。決定記録 0011）／ 職員の貼り付けはここからも（利用者は「利用者」画面から）／ **月の勤務表を貼り付ける**（Excel の表: 日付の行、名前の列、マスが番の略称。照らせない略称は 1 回だけ番か休みを選ぶ（選ぶまで「この内容で入れる」は押せず、理由を添える）。読んだ対応・休みとして読んだ印・ほかの n 人は今のまま・空欄だけの日と今日より前の日は入れない、をプレビューに出す。名簿と照らせない名前は入れずに知らせる。21 日〜20 日の表も読む。同じ日を貼り直すと置き換え、表にない職員は変えない。入れた日は朝の帯が「勤務表どおり（11/6）に並べました」になる。決定記録 0015）。変えるとトーストと「元に戻す」。
- ほかの端末からも見る（施設コード。決定記録 0009）: 既定はブラウザ内保存で、コードは出さない。「この施設を同期する」で 6 文字の乱数のコードを発行し、その端末の内容を送って同期に切り替える。同期中はコード（読み上げは 1 文字ずつ）と QR（`/setup?join=コード`）を出し、「この端末だけにする（同期をやめる）」は一文の確認のあと、いまの内容をその端末に写してから切る。参加は「施設コードで参加」（入力。はじめの画面にも 3 つ目のボタンとして出す）か QR。参加するとスマホ幅は自分の予定へ、PC はボードへ移り、「施設コード … で参加しました」と一言出す。コードに内容がなければ「届いていません」と「この端末だけにする」。環境変数がなければ同期の項目を出さない。同期中はボードの ⋯ に「サンプルに戻す」を出さない。「施設コードは暗証番号ではありません」「試用では架空の名簿だけ」と画面に書く。見出しの「同期中」「この端末の内容」は §0.8。
- 「自分の施設で始める」は、業務の種類・番・業務表をサンプルの雛形から写し、雛形のグループを入れたグループへ並び順で当てはめる。登録するとブラウザの中の内容は入れ替わる（ボードの ⋯ でサンプルに戻せる）。

取込の規則: 1行1件、カンマ・タブ・全角カンマ。空行は無視。失敗行は行番号と理由を出し、他は取り込む。

## 3A. 設定の「データの備え」（グリル U9）

- 「この施設を書き出す（ファイル）」: 保存しているイベント列を JSON で書き出す。
- 「ファイルから読み込む」: 書き出したファイルを選ぶ → 「いまのこのブラウザの内容と置き換わります」→「置き換えて読み込む」。施設コードで同期しているあいだは読み込めない（ほかの端末も置き換わるため）。


## 4. 自分の予定（スマホ）

**上部**: 「佐藤 さんの予定」・「11/3（火）早番A 7:00–16:00」・「自分ではない（名前を選び直す）」。右に「印刷」と、直前の操作があるときは「元に戻す（操作名）」（トーストが消えたあとも戻せる。§0.7）。その下に常に1行「**困ったら 佐藤（リーダー）PHS 801**」。リーダーが休憩中なら「佐藤（リーダー）は休憩中 14:00–15:00 → 木村 PHS 807」。勤務中の人がいない時刻は「近くの職員へ（詰所）」。決め方は決定記録 0006。

**本文**
- 「**いまの時間の予定**」: 業務名・時刻・場所・人数 or 様名・一緒に（名字。ひとりなら「なし（ひとりで入ります）」）。押すと業務詳細。勤務中で予定のない時間は「いまの時間の予定はありません（14:00 から 見守り）」と1文。
- いまの予定がなければ「**最初の予定**」（勤務前）または「**つぎ**」を同じ大きさで出す。初回の人には、勤務中も含めて「お願いすること」「お願いしないこと」「物品」を開いて出す。
- 「きょうの流れ」: 時刻順（開始–終了）。始まった行の右に「□ 終わったら押す」（1 タップ。もう一度押すと外れる。休憩・見守りには出さない。先の行には出さない）。印の付いた行は「✓ 終わった」と薄く。時刻が過ぎただけの行は通常の濃さ（読み上げだけ「（時刻を過ぎた予定）」）。いまの行に「いま」、その位置に「● いまの時間」。最後に「退勤」。休憩は「休憩」とだけ出す（丸数字はボードだけ）。押したあとは画面下に一言と「元に戻す」（リーダーは［自分｜全体］の上）。
- 夜勤明けの人（前の業務日の勤務がまだ続いている人）は、前の業務日を開く（翌朝 7:00 なら「11/3 の翌7:00」。夜勤帯の業務はその夜勤が始まった業務日に属する）。名前の一覧でも「夜勤明け」の印をつけて、きょうの出勤者の前に並べる。前の業務日に勤務表がない（デモの初日）夜勤の人は、勤務前の朝の時刻を「翌」として読む。
- 時間割がまだない日は「きょうの時間割はまだできていません。リーダーが作ると、ここに出ます。」
- 充足バッジ・一括・共通・ノンコアは出さない。持つのは「終わった」の印だけ。内容の記録はしない（決定記録 0010）。

**共有端末**: はじめに名前を選ぶ（その端末が覚える。初回の人に「初回」）。「自分ではない（名前を選び直す）」で変えられる。出勤者が0人なら1文と「もう一度読み込む」。

**リーダー**: 画面下に［自分｜全体］。翌日の朝は、全体の上に「夜勤明け（前日の夜勤の業務）」を見るだけで出す（変えるときは前日のボード。決定記録 0007）。リーダーの番（`leaderRank`）の人に出す。施設がリーダーの番を決めていなければ、出勤している人全員に出す。

**印刷**（⋯ → 印刷、A4 縦 1 枚）: 名前・日付・番・勤務時間・印刷時刻、困ったら（勤務の間の相談先を時間帯ごと）、きょうの流れ（時刻・業務名・場所・一緒に・退勤）。

### 4.1 全体（リーダーのスマホ）
- 上部: 「更新 10:07」・「担当未定 2件」「担当あと1人 1件」「終わっていない 2件」（押すと該当行へ。担当未定はこれからの分。終わっていないは、自分の勤務が始まってから終わりの時刻を 15 分過ぎて印の無い行。押すたびに次の行へ。決定記録 0010）。開いたら、いまの時間の行へ寄せる（一覧の中に「● いまの時間」）。決定記録 0007。
- 時間順の一覧: 時刻・業務名・人数 or 様名・担当の名字・バッジ。休憩の行は「休憩: 名字」。時刻を過ぎて印の無い行は通常の濃さで「（時刻を過ぎました）」と「□ 終わったら押す」（担当がいなければ「担当: なし」）。印の付いた行は薄く「✓ 終わった」の文字だけ（外すのは ⋯ から）。＋は過ぎた行に出さない。誰もいない休憩カードは出さない。**各行に「⋯」**（終わった・中止・ずらす・担当を外す）、**未充足の行に「＋」**。翌朝の「昨夜の夜勤の業務」には夜勤帯の枠を全部出し、✓ と「（時刻を過ぎました）」を見るだけ。
- 画面下（親指の位置）: クイック操作2つ［欠勤・早退｜付き添い・外出］と「元に戻す」（直前の操作名つき）、その下に［自分｜全体］。休憩をずらすは「⋯ → ずらす」（決定記録 0004 §8）。
- ⋯ のシート: 終わった（「終わったにする」／「『✓ 終わった』を取り消す（□ に戻す）」。休憩・見守りには出さない）／ずらす（30分後へ・30分前へ・15分後へ・60分後へ。休憩はその人の分だけ、勤務時間内）／担当を外す（名字ごと）／中止（一覧に残る。中止を取り消せる）。どれも1タップで決まり、トーストと「元に戻す」。
- ＋ のシート: ボードのパネルと同じ（問題なし → ほかの人（注意 n・勤務外 n））。まだ足りないときは開いたまま。
- クイック操作（3タップ）:
  - 付き添い・外出 → 利用者を選ぶ → この内容で決定。既定: 受診の付き添い、今から90分、担当は空き（プレビューで「問題なし」の先頭を1タップで付けられる）。重なる休憩は後ろへずらす。同じ利用者の同じ時間の個別業務は「中止」の候補に出す。
  - 欠勤・早退 → 職員を選ぶ → この内容で決定（出勤前は欠勤、勤務中は今の時刻で早退）。勤務中でも来ていなければ、プレビューの［早退｜欠勤（来ていない）］で1タップで直す。
  - 付き添いで同じ方の業務: 個別ですっぽり入るものは中止（既定でチェック）、端だけ重なるもの・一括の対象の方から外すものは候補（チェックなし）。
- 付き添いのプレビューでは、種類（受診・外出・入院・その他）・開始（±15分）・長さ（60/90/120/180分）・担当（「担当を選ぶ」で ＋ と同じ候補）を変えられる。変えなければ既定のまま。
- 決定後は一覧に戻り、変わった行を3秒強調（文字でも「変わりました」）し、その行へ移る。

## 5. 業務詳細（スマホ）

> 0004 §4: 「対象の方」に、方ごとに時刻とサポートが必要なことの1行を出す（担当の人に、勤務時間中だけ。表示名は設定に従う）。一括の枠で時刻が違う方は、その時刻を出す。

上から:
1. 戻る。業務名・時刻・場所・一緒に（ひとりなら「なし（ひとりで入ります）」）。その下に「□ 終わったら押す」（1 タップで「✓ 終わった」。もう一度で外れる。画面下に一言と「元に戻す」。休憩・中止・見守りには出さない。一緒に入る人がいれば「一緒に入る人の分も終わったら押します」、対象が複数なら「対象の方 全員が終わったら押します」と添える。決定記録 0010）。画面の最後にも「自分の予定へ戻る」。
2. **あなたにお願いすること／お願いしないこと**（太枠）。
3. 物品の場所（1 行）。
4. 対象の方（人数。表示名の設定に従う。10人までは全員、それより多ければ6人まで出して「ほか n 人を見る」で全員）。並びは 時刻が違う方 → サポートのある方 → 部屋番号。サポートの 1 行は名前の下（名前は繰り返さない）。注記「お一人ずつの介助のしかたは載せていません。一緒に入る人か相談先に聞いてください」（勤務前は「勤務が始まる hh:mm からここに出ます（共有の端末でも見られるので、担当の人に勤務中だけ出します）」と理由を添える）。手順より上に置く（「この時間に、誰に、どんな注意が要るか」を先に。決定記録 0010 決定 5）。
5. この施設の手順（番号つき 3〜6 行）。
6. 困ったら: いまの相談先（先の業務ならその時刻の相談先。決定記録 0006）と、業務の相談先。一緒に入る人（名字・PHS）は見出しのすぐ下に出す（休憩には出さない）。
内容の記録のボタンは置かない。手順が未登録なら「手順はまだ登録されていません。相談先に確認してください」。

**目的**: 使い方を忘れたときに、どこで何をするかを引く。上部バーのナビ「使い方」から。
