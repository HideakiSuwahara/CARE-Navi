# 画面仕様

UX/UI案（9枚のアートボード）を実装の仕様に落としたもの。文言は docs/wording.md、チェックは docs/checks.md、データは docs/data-model.md を参照。

## 0. 共通の規則

### 0.1 見た目
- 書体: Noto Sans JP。本文 15–16px、カード見出し 15px 太字、補足 12–13px。スマホは本文 16px。
- 地色 `#F3F3EF`、面 `#FFFFFF`、罫 `#E3E3DE`、文字 `#1C1F23`、補足文字 `#5B6168`、主色 `#1D5C8A`（ボタン・選択・担当チップ）。
- 状態は**文字**で示し、色は補助。色で区別するものは明度も変える。
- 押せる領域は 44px 以上（PC の小さなボタンも 32px 以上）。
- アイコンは線画の SVG のみ。絵文字は使わない。
- 現在時刻ラインは `#C2410C` の 2px 線と時刻タグ。1分ごとに更新。

### 0.2 業務カード（ボード・一覧で共通）
| 要素 | 表示 | 備考 |
|---|---|---|
| 業務名 | 太字 | |
| 時刻 | `10:30–12:00` | 翌日分は `翌2:00` |
| 対象 | チップ `個別 田中様` / `一括 20人` / `共通` | 一括は対象者一覧を開ける |
| 補足行 | 場所 ・ 区分名 ・ 必要n ・ 条件: タグ | 入るものだけ |
| 担当チップ | 名字のみ。主色の薄い背景 | 初回の人は `加藤 初回` |
| 充足バッジ | §0.3 | 未充足のときだけ |
| 「＋ 担当を追加」 | 破線の丸ボタン | 未充足カードのみ常時表示。充足カードはホバー／長押しメニューから |
| 休憩カード | 薄い紫地 `#F3F1F8`、破線枠、文字 `#4E4870` | 区分の集計に入れない |
| 継続カード（見守り） | 薄い青地 `#F7F9FB`、列の左 30% 幅 | 同じ時間帯の他カードは右側に並ぶ |
| 中止 | 取り消し線、灰色。カードは残す | 「中止」の文字を付ける |

### 0.3 充足バッジの文言（必要人数 n、割当 a）
| 状態 | 文言 | 見た目 |
|---|---|---|
| a = 0 | **担当未定** | 橙系 `#FFE7D6` 地・`#8A3B00` 文字、カードは破線枠 |
| 0 < a < n | **担当あと {n−a} 人** | 黄系 `#FFF3C4` 地・`#6B4E00` 文字、カード枠は `#E6CF7A` |
| a = n | （無印） | |
| a > n | **{a−n} 人 多め** | 灰地。間違いとは限らないので控えめ |
バッジの横に小さく「予定の担当枠の差分です」。ヘルプに「ケアの未実施人数ではありません」。「人手不足」「不足」は使わない。

### 0.4 候補一覧（担当を追加）
3段に分け、各行に理由を一文。並び順は 問題なし → 注意 → 勤務外・休み。
- **問題なし**: 条件を満たし、時間も空いている。「10:30–12:00 は空いています。条件「入浴担当可」あり」。部分参加できる人は「11:30 まで◯◯。11:30–12:00 なら入れます（部分参加）」。
- **注意**: 追加できるが理由を確かめる。重複・休憩・条件不一致・初回のみ。
- **勤務外・休み**: 勤務予定なし／勤務前／勤務後／欠勤・休み。休みの人には「追加」ボタンを出さない。
末尾に固定文「注意がある人も追加できます（同じ人を同じ業務に二度は入れられません）。追加のあとは画面下の「元に戻す」で取り消せます。」

### 0.5 プレビュー→適用
クイック操作と「型を当てる」は、変更をいきなり書かず、**こう変わります** の一覧（行ごとにチェックボックス）を見せてから「適用する（元に戻せます）」。
- 行の種類: `追加` `外す` `中止` `ずらす` `担当` と、結果として出る `担当未定` / `担当あと n 人`。
- 重なりによる「外す」は検証側が決定的に生成し、「（◯◯と重なるため）」を添える。
- 適用は1つの batchId にまとめる。元に戻すと全行が戻る。

### 0.6 トーストと元に戻す
- 操作直後、画面下中央に黒いトースト「山本さんを「入浴介助 10:30」に割り当てました［元に戻す］」。8秒。
- 「元に戻す」ボタン（ツールバー）と Ctrl+Z／⌘Z は履歴 10 手まで。
- 戻した結果もトーストで知らせる（「戻しました」）。

### 0.7 更新時刻
- ボード・きょうの全体の右上に「更新 10:07」。**時刻のみ**。誰が変えたかは履歴パネル（「履歴」ボタン）で見る。
- 同期中は「更新 10:07 ・ 同期中」、オフラインは「オフライン（この端末の内容）」。

### 0.8 利用者の表示名
- ボード（施設PC）: 常にフルネーム＋部屋。
- 手元画面（マイナビ・業務詳細・きょうの全体）: 施設設定 `residentDisplayMode` に従う。既定は **部屋番号＋姓**（例: `203 田中`）。`roomOnly` は `203`。
- 印刷「自分の予定」も手元画面の設定に従う。

### 0.9 空状態・エラー
- どの空画面にも「次にすること」を1文と1ボタン。例: 「まだ今日の時間割がありません」→「朝の準備へ」。
- エラーは理由と次の手を書く。「保存できませんでした。この端末には残っています。電波の届く場所で自動的に送ります」。
- 読み込み中はスケルトン。1秒以上かかる処理には文言を出す（「型を当てています…」）。

## 1. ボード（PC・タブレット）

**目的**: 一日の時間割を見渡し、割当・変更・取消を行い、担当未定を把握する。

**構成**
- 上部バー: ロゴ「ケアナビ」＋施設名 ／ タブ「ボード」「朝の準備」「見直し」「設定」 ／ 日付（‹ 11月3日（火） ›） ／ 「更新 hh:mm」 ／ 「分担表を印刷」。
- 表示切替: 横軸 [グループ | 職員]、時間 [06–22 | 全時間（翌6:00まで）]、グループ絞込チップ、右に「担当未定 n」「担当あと1人 n」（押すと該当カードだけ強調）、「元に戻す」。
- 時間割: 左に時刻ガター（1時間ごと、1分=2px）、列＝グループ（東フロア／さくらユニット／共通）。カードは絶対配置。現在時刻ライン。
- 右パレット「きょうの出勤者」: 名字・役職・役割・件数。勤務前の人は灰色（「遅番 11:00〜」）、初回の人は「初回」タグ。別枠「本日休み」に、休みの人と「役割◯◯の枠 n 件が担当未定」。
- トースト（§0.6）。

**操作**
- 割当: パレットのチップをカードへドラッグ（dnd-kit、タッチ対応、キーボード操作可）。カード上のチップを別カードへドラッグで移動、パレットへ戻すと取消。
- 同じ結果をタップで: カードの「＋ 担当を追加」→ 候補一覧（§0.4）。
- 長押し／右クリック: 「中止」「ずらす（−60 −30 −15 ｜ +15 +30 +60 ｜ 時刻を入力）」「担当を外す（名前を選ぶ）」「対象者を見る」「詳細」。
- カードをクリック: 詳細パネル（右側 or モーダル）。場所・対象者一覧・担当・手順・物品・相談先・メモ。
- 時刻のドラッグ変更は作らない。

**状態**: 読み込み中／空（今日の時間割なし→「朝の準備へ」）／通常／絞込中／オフライン。

**スマホ**: ボード（表形式）は出さない。スマホのリーダーは「きょうの全体」（§9）を使う。タブレットは横向きで表形式。

## 2. 職員ビュー（PC）

**目的**: 重なり・偏り・誰もいない時間帯を確かめる。印刷すると分担表。

**構成**: 縦＝職員（名字・役職・役割・勤務時間・件数・予定時間）、横＝時間（1時間ごとの罫）。担当カードを帯で描く。勤務前・勤務後は斜線の帯と「勤務前（11:00から）」。休憩は紫の破線帯。重なりは橙の二重枠と「重複」の文字、行の背景を薄橙にし、左に「重なり 1件（11:00–11:30）」。休みの人は灰色行に「本日休み ・ 役割◯◯の枠 n 件が担当未定」。最下段に「見守り（東フロア担当）」の連続カバー行。空き区間は破線の橙で「13:00–14:00 担当未定」。

**操作**: 帯をクリックで詳細。帯からの D&D は作らない（ボードで行う）。「分担表を印刷（A4横）」。

**印刷**: 上部バーとツールバーを隠し、職員×時間の表を A4 横 1 枚（職員 12 人まで）。文字 10pt 以上。日付・施設名・印刷時刻を頭に。

## 3. 朝の準備（PC・タブレット）

**目的**: 出勤者に役割を付け、型を当て、例外だけ直す。目標 1分。

**構成**
- 3ステップの帯（現在のステップを黒）。
- 「今日の出勤者」表: 名前・役職 ／ 役割ボタン（「早番A ▾」。押すと役割チップの一覧が行内に開く）／ 勤務時間（役割から自動。手入力で上書き）／ 初回チェック ／ 「休み」トグル。右上に「先週の同じ曜日と同じにする」。下に「＋ 応援・スポットの人を追加」。
- 右「一日の型を選ぶ」: ラジオ（平日／入浴日／日曜。各枠数と説明）。「この型で今日の時間割を作る」。
- 「できました」: 「58枠のうち 55枠に担当が付きました」＋ 担当未定 n（業務名、役割）、担当あと1人 n（業務名、時刻）。「ボードで直す」「今日の形を「型」として保存」。

**操作の規則**
- 役割を付け替えると勤務時間も役割の既定に戻る（手入力済みなら確認）。
- 型を当てるのは何度でも可。2回目以降は「今日の時間割を作り直しますか？ 手で直した担当は保たれません」と確認し、プレビュー（§0.5）を経る。
- 「休み」にした人の担当は外れ、該当枠は担当未定になる（プレビューで一覧）。
- 「型として保存」は時刻・役割・必要人数の構造だけを保存し、人は保存しない。

**空状態**: 出勤者が 0 人なら「出勤者に役割を付けると、型を当てられます」。

## 4. 担当を追加（候補と理由）

§0.4 のとおり。PC ではボード右側のパネル（480px）、スマホでは下から出るシート。見出しに対象業務（名前・時刻・グループ・場所・対象チップ・充足バッジ・必要/配置/条件）。「追加」を押すと即時に割当（警告つきでも可）、トースト。二重登録は「追加」ボタン自体を出さない。

## 5. 見直し（PC）

**目的**: 区分×時間帯と、ノンコアの枠を見て、ずらす・任せる・減らすにつなげる。

**構成**
- 期間切替 [火曜（11/3） | 今週]。
- 常時表示の前提帯: 「予定時間ベース（一日の型と当日の予定から計算。実施時間ではありません）」「配置を見直すための数字です。職員の評価には使いません。職員個人の内訳は出しません」。
- 左「区分 × 時間帯」: 1時間ごとの積み上げ棒（コア `#1D5C8A`、ノンコア `#E0A83A`、休憩 `#D9DAD4`）。背後に介護助手等の勤務帯を斜線で敷く。凡例に合計時間。下に「ノンコア業務のうち、介護助手の勤務帯の外にある予定: n時間」。
- 右「ノンコアの枠」: 業務・時刻・役割・勤務帯の中/外・見直し（ずらす／任せる／減らす）。担当未定の枠は薄橙地。「ほか n 枠を見る」。
- 下に厚生労働省の4ステップとの対応 4 枡。

**操作**: 「ずらす」→ 時刻入力（勤務帯の中の候補時刻を先に出す）→ プレビュー→適用。「任せる」→ 候補一覧（担当条件を満たす役割の人を先頭）。「減らす」→ 「今日は中止」または「型から外す」を選ぶ。

**計算**: 予定時間＝各業務の (endMin−startMin) × 必要人数。休憩は別集計。区分なしは「区分なし」として灰で積む。職員個人別は計算も表示もしない。

## 6. はじめの設定（PC）

**構成**
- 最初の2択: 「サンプル施設で試す」（主色、押すとサンプルが読み込まれボードへ）／「自分の施設で始める」。
- 3ステップのカード: ①施設の名前＋グループ（1行1つ。「共通」は自動） ②利用者を貼り付け（名前、グループ、部屋。カンマ・タブどちらでも） ③職員を貼り付け（名前、役職、担当条件タグ 任意・複数）。
- 「最初から入っているもの」: 役割枠 8 種のチップ、業務の型 約20種、一日の型（従来型／ユニット）、区分。
- 「スマホとつなぐ」: 施設コード（例 `HMWR-7K2Q`）と QR。説明「職員のスマホで読み取ると、同じ時間割が表示されます」。注記「デモは施設コード方式。本番は認証と権限が必要です」。
- 「あとで続ける」「登録して、明日の準備へ」。

**取込の規則**: 1行1件。区切りはカンマ／タブ／全角カンマ。空行は無視。グループ名が未登録なら作成を提案。重複名は末尾に（2）を付けて確認。失敗行は行番号と理由を表示し、他は取り込む。

**設定（同じ画面の下部または別タブ）**: 表示名モード、チェックの扱い（警告して許可／禁止）、初回の方だけの警告 ON/OFF、ボードの既定範囲、区分の名称、役割枠の時間、休憩の既定。

## 7. マイナビ（スマホ）

**構成**
- 上部: 名前「佐藤 みき さん」、日付・役割・勤務時間・所属。「職員を切り替え」（共有端末モード。名前一覧から選ぶ。PIN は作らない）。
- 「いまの時間の予定」: 現在時刻を含む自分の業務。主色の太枠。業務名・時刻・対象チップ・場所・一緒に（他の担当の名字）・「場所・手順・物品・相談先を見る →」。複数あれば縦に並べる。無ければ「いまの時間に予定はありません。つぎは 10:30 入浴介助」。
- 「つぎ」: 次の1件。未充足なら「担当あと1人」を添える。
- 「きょうの流れ」: 時刻順。過ぎた予定は薄い文字。現在は「● いまの時間」。休憩は紫の文字。最後に「退勤」。
- 注記「時刻が過ぎた予定は薄く表示します。終わったかどうかは記録しません。」
- 下部バー: きょう ／ 全体（リーダーのみ） ／ 自分の予定を印刷。

**規則**: 「実施中」「完了」「済」の語を使わない。自動で状態を変えない。

## 8. 業務詳細（スマホ）

**構成（上から）**
1. 戻る、閲覧者名（初回なら「（初回）」）、勤務時間。
2. 業務名・時刻・対象チップ。場所・一緒に（名字＋役職）。
3. **あなたにお願いすること／お願いしないこと**（主色の枠。型の scopeNote / outOfScopeNote）。
4. 場所と物品。
5. この施設の手順（番号付き 3〜6 行）。
6. 対象の方（人数、表示名モードに従う 3 列グリッド、6 人まで表示して「ほか n 人を表示」）。注記「利用者ごとの介助方法は、ここには載せていません。相談先に確認してください。」
7. 困ったときの相談先（薄橙の枠。一緒に入る職員、きょうのリーダー、PHS 番号）。

**規則**: 記録ボタンは置かない。対象者なしの業務は 6 を出さない。手順が未登録なら「手順はまだ登録されていません。相談先に確認してください」。

## 9. きょうの全体（リーダーのスマホ）

**構成**
- 上部: 「きょうの全体」「更新 hh:mm」、[自分 | 全体] 切替。グループチップと「担当未定 n」。
- クイック操作 3 ボタン: 欠勤・早退 ／ 付き添い・外出 ／ 休憩をずらす。
- 時間順の一覧（カードの簡易版: 時刻・業務名・対象チップ・バッジ・担当の名字）。長押しで「中止」「ずらす」「担当を外す」「担当を追加」。
- クイック操作のシート（下から）: 
  - 付き添い・外出: だれ（利用者）／なに（受診の付き添い・外出・入院の付き添い・その他）／いつ／だれが → 「こう変わります」→「適用する（元に戻せます）」。
  - 欠勤・早退: だれ／いつから → その人の担当を全部外す一覧と、結果の担当未定一覧 → 適用。
  - 休憩をずらす: どの休憩／だれ／何分 → 重なりの確認 → 適用。

**規則**: 変更はすべて 3 タップ以内。適用前に必ずプレビュー。適用後は「全体」に戻り、変わった行を 3 秒強調。

## 10. 印刷

| 印刷物 | 元画面 | 体裁 |
|---|---|---|
| 分担表 | 職員ビュー | A4 横 1 枚。職員×時間。日付・施設名・印刷時刻。担当未定の枠は一覧で下に |
| 自分の予定 | マイナビ | A4 縦 1 枚。きょうの流れ＋各業務の場所・一緒に・相談先。表示名モードに従う |

`@media print` でナビ・ボタンを隠し、色は白黒でも読めるよう文字と罫で表す。
