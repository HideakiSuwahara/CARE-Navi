# 3分動画の構成

方針: 動きは3つだけ（①現在時刻ラインが進む ②職員チップが落ちてバッジが消える ③別画面に即反映）。それ以外は静か。色は補助、文字が主。字幕で前提を明示する（同期の方式、効果は仮説、AIは使わない）。記録機能は出さない。

## 構成

| 時間 | 場面 | 画面 | ナレーション（案） | 字幕 |
|---|---|---|---|---|
| 0:00–0:25 | 問題 | ホワイトボードの写真（架空・再現）、電話を取る手 | 「介護現場の今日の仕事は、慣れた人の頭の中と口頭にあります。足りない枠は、電話や口頭で人を探しています。」 | 再現・架空／介護職員の必要数 2040年度 約272万人（厚生労働省推計） |
| 0:25–0:40 | 転換 | 黒背景にテロップ | 「人に仕事を積むのをやめて、仕事に人を付ける。ケアナビです。」 | 仕事に、人を付ける。 |
| 0:40–1:05 | 朝は1タップ | ボードで「次の日」→「今日の時間割を作る」（勤務表どおりに出勤者と番が並んでいる）→「この内容で作る」 | 「朝は、先週と違うところだけ直して、1回押すだけ。業務は番に束ねてあるので、全部の枠に担当が付きます。介護助手が休みの日は、その枠がそのまま『担当未定』で見えます。」 | 業務は番に束ねてある／押すのは1回 |
| 1:05–1:35 | ボード | ボード（現在時刻ラインが動く）→ 入浴介助「担当あと1人」→ 休憩中の人（伊藤。11:00–12:00 休憩）を落とす→理由→元に戻す→「＋」で空いている人（高橋）を「追加」→解消 | 「ボードは縦が時間、横がフロア。入浴に1人足りない。休憩中の人を入れようとすると理由が出ます。元に戻して、＋から空いている人を選ぶ。決めるのは人。道具は理由を見せるだけ。」 | 担当未定 ≠ 人手不足（予定の担当枠の差分） |
| 1:35–2:05 | 変更は3タップ | リーダーのスマホ［全体］→ 付き添い・外出 → 利用者を選ぶ → こう変わります（重なる休憩は後ろへずらす）→「この内容で決定」→ 空いた枠に「＋」で付ける | 「10時過ぎに受診が入った。フロアのスマホで、付き添い、田中様、決定。3回押すだけ。休憩は消さずに後ろへずらす。空いた枠はすぐ分かる。」 | 変更は3タップ、フロアのスマホで |
| 2:05–2:30 | 手元に反映 | 実機のスマホ（またはスマホ幅の窓）の自分の予定（初回の応援）→ 業務詳細 | 「応援の人のスマホには、お願いすること・しないこと、場所、一緒に入る人、物品、困ったときの相談先。初日から、段取りで迷わない。」 | 施設コードで同期（デモ）／本番は認証と権限 ※同一ブラウザ内で撮った場合は「同一ブラウザ内のデモ」 |
| 2:30–2:45 | 業務の見直し | 業務の見直し（今週） | 「施設がノンコアに分けた業務が、どの時間帯に集まるかを、予定時間で 1 枚に。数字は業務に付けて、人には付けない。見直すのは人です。」 | 予定時間ベース／職員の評価には使わない |
| 2:45–3:00 | 締め | ロゴ → 開発過程の一枚（構想→10の問い→独立レビュー→決定記録→レビューループ） | 「Claude Code で作った、AIを使わない道具です。業務が見えれば、初めての人も段取りで迷わない。」 | 効果は仮説。初見試用 n=◯ の実測のみ掲載 |

## 収録メモ
- 操作クリップは Playwright で自動撮影（同じ操作を同じ速度で再現できる）。スマホは実機の画面収録。
- ナレーションは発表者が収録。BGM は無しか小さく。
- 画面収録は 1440×900、スマホは 390×844。サンプル施設は開いた瞬間を 10:12 として時計が進むので（決定記録 0018）、?now を付けずに撮る（現在時刻ラインが動くところが見せ場）。撮る前にボードの ⋯ →「サンプルに戻す」。
- 出すデータはすべて架空（ひまわり苑）。実在の施設名・人名を出さない。
- 引用する試用の声は了解を得たものだけ。無ければ出さない。
- 「ひとこと変更」「AIが提案」などの表現は使わない（決定記録 0002）。
- 直近の機能（終わった枠の灰色・利用者ごと・設定の追加変更）は新しい場面にしない。終わった枠の灰色は 1:05 のボードに最初から映る（食堂準備 ✓ 終わった）。利用者ごと・設定の追加変更は README と使い方に置く（3 分の筋を変えない）。
