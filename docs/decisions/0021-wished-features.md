# 0021 元に戻すの履歴・続けて埋める・手が空いたら・担当の入れ替え、始まる前の「終わった」は一言聞く

- 日付: 2026-11-07
- 状態: 決定。同日に実装
- 置き換える決定: 0010 の「1 タップで付け外し」を、枠の始まりより前に付けるときだけ 2 タップ（一言聞く）に
- 関連: 0002（AI・自動配置を使わない）、0003（押す回数）、0010（終わった）、0014（主任の日常）、グリル `docs/grills/2026-11-07-wished-features.md`

## 背景

ループ 19 で 3 ペルソナが一日を通して使い、「欲しくなった機能」が出た。作者の答えで 1〜4 を作り、時刻前の印は一言聞くことにした。

## 決定

1. **元に戻すの履歴**: ボードの「元に戻す」の横に「履歴」。見ている日の操作（と日に依らない操作）を新しい順に 10 件、時刻つき。選ぶと、新しい方から選んだところまで順に戻す。その端末の操作だけ。
2. **続けて埋める**: 担当を追加のパネルで、追加のあと「担当がそろっていない次の枠へ →」。見ているグループの中で時刻の順。決めるのは人で、自動では付けない。
3. **手が空いたら**: 自分の予定のきょうの流れで、勤務中の 30 分以上の空きに「予定のない時間」と、その時間に始まり自分が入っても注意の出ない枠の名前を 3 件まで（「リーダーに声をかけてから」）。札・件数・「担当未定」の語は出さない。自分では付けない。
4. **担当の入れ替え**: 業務の詳細の担当の行から、時間の重なるほかの枠の担当の人と入れ替える。こう変わりますを見てから決める。1 バッチで元に戻せる。注意は止めずに一文。
5. **始まる前の「終わった」**: 始まりより前に押すと「まだ始まる前です。もう一度押すと「終わった」の印が付きます」（業務日の分で比べる。夜中の 2:10 は 翌2:10）。始まった後は 1 タップのまま。
6. 新しいイベントは無い。

## 理由

- 今日のリーダー: 途中の変更（欠勤のあと）を埋める回数が減る（1 件 3 回 → 2 回）。入れ替えが 4 回以上 → 3 回。戻す前に何が戻るかが見える。
- 応援・新人: 空き時間に何をしてよいか迷わない（決めるのはリーダー）。先の枠に印を付けてしまう押し間違いが減る。

## 見直す条件

- 履歴をほかの端末の操作にも広げたい声、施設が決めた空きの仕事の一覧を持ちたい声。
