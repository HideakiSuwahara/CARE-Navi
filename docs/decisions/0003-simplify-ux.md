# 0003 画面を5つに減らし、押す回数を最少にする

- 日付: 2026-11-02
- 状態: 決定
- 関連: 0001（スコープ）、0002（AIを使わない）、docs/reviews/2026-11-02-loop1.md

## 背景

UX/UI案（9画面）を4つのレビュー（初見UX・現場・アクセシビリティ・範囲）で点検した。開発チームの最優先は「介護職員が迷わない」「リーダーが設定しやすい」「表示は極力シンプル」「ワンクリック。押す回数を最少に」。レビューは次の点で一致した。

- 画面と切替が多く、初見で次の一手が分からない（ナビ4項目、ボードの切替5群）。
- 朝の準備は役割付けだけで20タップ以上。付き添いの追加は約10タップで、3タップの原則に反する。
- 人に数字が付いている（パレットの件数、職員ビューの予定時間）。原則5に反し、見張られているように見える。
- 休憩を「外して担当あと1人」と出す案は、休憩を消す。休憩は誰かで埋める枠ではない。
- スマホの長押しは初見で見つからず、キーボードでも操作できない。

## 決定

### 1. 画面は5つ
| 端末 | 画面 | 中身 |
|---|---|---|
| PC | **ボード** | 時間割。横軸の切替［グループ｜職員］だけ。担当の追加は右のパネル。朝の準備は、その日の時間割が空のときボードの上に出る「今日の時間割を作る」帯（タブにしない）。分担表の印刷は職員表示から |
| PC | **業務の見直し** | 週だけ。図1枚と、ノンコアの枠一覧 |
| PC | **設定** | はじめの設定と同じ画面。サンプル／自分の施設、名簿の貼り付け、施設コード、表示名、初回の方の警告 |
| スマホ | **自分の予定** | いま／つぎ／きょうの流れ。リーダーには下部に［自分｜全体］が出る（全体＝きょうの全体とクイック操作） |
| スマホ | **業務詳細** | お願いすること／しないこと、場所と物品、手順、対象の方、相談先 |

「職員ビュー」「朝の準備」「担当を追加」「きょうの全体」は独立した画面にしない。

### 2. 朝は1タップ
- 「今日の時間割を作る」を開いた時点で、**先週の同じ曜日の番（役割）**と**曜日の業務表（一日の型）**が入っている。違うところだけ直して **「この内容で作る」1タップ**。
- 初回の作成はプレビューを挟まない（作った直後のトーストで元に戻せる）。作り直し（2回目以降）だけ確認する。
- 「今日を業務表として保存」はボードのメニューへ移す（朝の画面に置かない）。
- 「目標1分」などの急かす表示は出さない。

### 3. スマホの変更は3タップ以内（既定値を入れておく）
- **付き添い・外出**: ボタン → 利用者を選ぶ → 「この内容で決定」。なに＝受診の付き添い、いつ＝今から90分（15分単位に丸め）、だれが＝空き（担当未定。プレビューの中で「問題なし」の先頭を1タップで付けられる）。
- **欠勤・早退**: ボタン → 職員を選ぶ → 「この内容で決定」。出勤前なら欠勤、勤務中なら今の時刻で早退。
- **休憩をずらす**: ボタン → 休憩を選ぶ → ずらす幅（+30分が既定）→ 決定。
- 一覧の各行に「⋯」（中止・ずらす・担当を外す）、未充足の行に「＋」を常に出す。長押しは補助。
- 「元に戻す」は画面下に常に出す（トーストが消えても押せる）。
- クイック操作のボタンは画面の下（親指の届く位置）に置く。

### 4. 人に数字を付けない
- パレット・職員表示から「件数」「予定時間」を外す。重なりだけ文字で示す。
- 業務区分（コア／ノンコア）はカードに出さない。業務の見直しだけで使う。
- 休みの人の行に「ずらす・任せる・減らす」を出さない（見直しの言葉）。代わりに「この人の番の枠 n 件が担当未定」とだけ書く。

### 5. 休憩は埋める枠ではない
- 休憩カードには充足バッジを付けない（必要人数は「同時に休める人数」の目安として持つが、未充足を警告しない）。
- 付き添い等で休憩と重なるときの既定は「**休憩を後ろへずらす**」（例: 鈴木の休憩① 11:00 → 12:00）。外すのではない。

### 6. 候補は「問題なし」を先に、他は畳む
- 担当の追加パネルは「問題なし」の人だけを開いて出し、「ほかの人（注意 3・勤務外 3）」は1タップで開く。
- 「部分参加（11:30 からなら入れます）」は作らない（担当に時間の範囲を持たないため）。重なりは注意の段に「11:30 まで◯◯と重なります」と書く。

### 7. 職員の画面は職員のための情報だけ
- 自分の予定に充足バッジを出さない（リーダー向けの情報で、職員には不安になるだけ）。
- 「一括」「共通」「ノンコア」などの仕組みの言葉を出さない。「20人」「田中様」とだけ書く。
- いまの予定が無い（勤務前など）ときは、**最初の予定**を詳細ごと先頭に出す。
- 画面の上に **「困ったら ◯◯（リーダー）PHS 201」** を常に1行。相談先がその時間に休憩中なら「休憩中 13:00–14:00」と代わりの人を出す。
- 職員に任意の「PHS」を持たせ、名簿の貼り付けに任意の列として足す。

### 8. ボードの表示を減らす
- 外す: グループの絞り込み、06–22／全時間の切替（現在時刻へ自動で寄せ、上下にスクロール）、カードの区分名、バッジ横の注記（ツールバーに1回だけ）。
- 見出しの件数は「担当未定 2件」「担当あと○人 1件」と単位を付ける。
- 充足済みのカードにも「＋」を出す（ホバーに頼らない）。カードは押すと詳細、詳細から担当の追加・中止・ずらす。

### 9. 業務の見直しは週だけ、判断を言わない
- 期間は「今週」だけ。4ステップの枡は画面から外す（説明は動画と文書で）。
- 「任せられる候補」「必要性を見直す候補」など、道具が要否・可否を判断する文言を出さない。事実（時刻・番・介護助手等の勤務帯の中か外か）だけ。
- 行ごとの3ボタンは「見直す ▾」1つ（ずらす／任せる／減らす）。
- 図は色だけに頼らず、ノンコアに斜線、休憩に点、数値の表を併記。

### 10. 設定は2項目
- 表示名（手元画面の利用者名）と、初回の方の警告 ON/OFF。チェックの「禁止」切替は出さない（禁止は二重登録だけ）。
- 2026-11-05: 決定記録 0011 で 3 項目目「職員の担当条件」を足した（職員ごとに条件を付け外し。等級は持たない）。
- 2026-11-06: 決定記録 0016 で「追加・変更」（施設の名前・グループ・番・職員・勤務表）と「ふだんの設定」の 2 区画に整理した。

### 11. 画面上の呼び方
| 仕組みの名前（コード・文書） | 画面の言葉 |
|---|---|
| 一日の型（DayPattern） | **業務表** |
| 役割枠（RoleSlot） | **番**（早番A、日勤B、介護助手…） |
| 型を当てる | **業務表から作る**（ボタンは「今日の時間割を作る」） |
| マイナビ | **自分の予定** |
| 見直し | **業務の見直し** |
| 適用する | **この内容で決定**（元に戻せます） |

### 12. アクセシビリティの下限
タップ領域 44×44px、スマホ本文 16px・補足 14px、担当未定・担当あと n 人の枠線は白地で 3:1 以上（`#B5651D`）、カード・チップは `button` でキーボード操作可（Space で持つ → 矢印 → Enter で置く）、印刷は罫と文字だけで意味が通る。

## 影響
- docs/screens.md を5画面の構成に書き直す。UX/UI案（モックアップ）も5画面＋状態違いで描き直す。
- ドメイン: 休憩はバッジ対象外・付き添いと重なる休憩はずらす提案、候補の部分参加をやめる、職員に任意の PHS、先週の同じ曜日から出勤者の番を引き継ぐ関数、付き添いの既定値。
- サンプルデータ: ユニットにも見守り、リーダー（早番A）を入浴から外す、スポットの最初に「到着・案内」、画面同士の数字をそろえる、番の名前をそろえる。

## 採らなかった案
- 区分（コア／ノンコア）をカードに出し続ける案: 日次の画面に見直しの数字・言葉を持ち込むため採らない。
- 朝の準備を独立タブで残す案: 空の時間割の上に出す方が「次の一手」が明確で、タブが1つ減る。
