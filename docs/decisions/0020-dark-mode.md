# 0020 ダークモード（紺の暗い画面）を入れる

- 日付: 2026-11-06
- 状態: 決定。同日に実装
- 関連: 0019（見た目。ダークモードは見送っていた）、グリル `docs/grills/2026-11-06-dark-mode.md`

## 決定

1. 色はトークン（`--cn-*`）で切り替える。暗い画面は紺の地（#0f1b2d）、一段明るい紺のカード、薄い青白の文字。強調の色は明るい空色、その上の文字は濃い紺。状態の色は同じ系統を暗い地に合わせる。
2. 既定は端末の設定に合わせる。設定の「ふだんの設定」で［端末に合わせる｜明るい｜暗い］。その端末のブラウザで覚える（同期しない）。
3. 印刷は明るいまま。
4. コントラストは明るい画面と同じ基準（文字 4.5:1、枠線 3:1）。状態は文字で示す（色は補助）は変えない。

## 理由

- 今日のリーダー・夜勤: 夜の詰所で画面がまぶしくない。端末を暗くしている人は何もしなくてよい。
- 審査員: デモ動画と同じ見た目で試せる。

## 見直す条件

- 暗い画面で読みにくい箇所の声 → トークンを直す。
