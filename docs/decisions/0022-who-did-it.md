# 0022 やった人を変える（代わってもらった・担当未定のまま誰かがやった）

- 日付: 2026-11-07
- 状態: 決定。同日に実装
- 関連: 0010（終わった）、0021（始まる前の終わった）、グリル `docs/grills/2026-11-07-who-did-it.md`

## 背景

作者の案。自分の番の仕事をほかの人に代わってもらったとき、担当を決めないまま誰かがやったとき、だれがやったかを残したい。

## 決定

1. ボードの業務の詳細の「終わった」の横に「やった人を変える」。担当がいれば一人ずつ「◯◯さんの代わりにやった人」、担当がいなければ「やった人を選ぶ」。
2. 選ぶと、その人を担当にし（代わりなら元の人を外し）、「終わった」の印を付ける。1 バッチで、1 回で元に戻る。新しいデータ・イベントは足さない（担当の付け替え）。
3. 選べるのはその日の勤務表にいる人。休み・勤務外・休憩と重なるなどは注意を一文出すが止めない（実際にやった人を記録するため）。すでにこの枠の担当の人は出さない。
4. 始まる前の枠には出さない。
5. 誰が押したかは出さない（0010）。人ごとの件数も出さない。

## 理由

- 分担表・自分の予定・印刷が、実際にやった人と合う。担当未定のまま終わった枠も、だれがやったかが残る。
- 元の担当は操作の履歴に残る。予定と実際の 2 つの名前をカードに並べない（カードが読みにくくなる）。

## 見直す条件

- 予定の担当も残して見たい声（データに「やった人」を別に持つ）。リーダーのスマホ・自分の予定からも付けたい声。
