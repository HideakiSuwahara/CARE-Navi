# 0015 職員・利用者を 1 人ずつ足す・直す・外す。月の勤務表は貼り付けで入れる（番は職員の属性にしない）

- 日付: 2026-11-05
- 状態: 決定。1 人ずつの欄は同日に実装。勤務表の貼り付けは次に実装
- 置き換える決定: なし（0001「勤務表ソフト・CSV 取込は貼り付けで代替」の延長。0011 の「職員の担当条件」の区画を「職員」に広げる）
- 関連: 0002（製品内で認識・AI を使わない → 勤務表の画像・PDF の読み取りは作らない）、0004 §3（足した方は標準どおり）、0013（朝の下書きは先週の同じ曜日の番）、グリル `docs/grills/2026-11-05-staff-entry-and-roster.md`

## 背景

作者がデモを触った感想（11/5）。「職員の一括登録はやりやすいが、個別の設定のやり方が分からない。項目ごとに枠がある入力に慣れている人も多い。早番・遅番は月の勤務表で決まっているので、先に一括で入れておきたい。勤務変更もよくあるので、入れたものを直せるように。形式が合わない施設のために今のやり方も残す」。

## 決定

1. **職員を 1 人ずつ足す・直す・退職にする**（設定の「職員」）。名前を押すとその人の欄（名前・職種・PHS）。「＋ 1 人ずつ足す」は同じ欄に担当条件の □／✓ が付く。退職は一文の確認を挟み、今日以降の担当と出勤を一緒に外す（職員ごと外れるので、押すのは最後に出た日の翌日と案内する。外れた枠は「担当未定」か「担当あと n 人」になる。過去の分担表からも名前が消える＝「退職日」を持つ形は「見直す条件」）。貼り付けは残す。同じ姓が 2 人いれば一覧に名を添える。
2. **利用者を 1 人ずつ足す・直す・退所にする**（利用者の画面の「1 人ずつ足す・直す」）。名前・グループ・部屋。退所は一文の確認を挟み、**今日以降の枠**の対象から外れる（過去の枠は履歴として残す。`resident.remove` の `fromDate`）。元に戻すと対象にも戻る。入院など戻ってくる方は外さないよう画面に書く。貼り付けは残す。
3. **職員に「ふだんの番」は持たせない。** 番はその日ごと（原則 4）。月の勤務表は **「月の勤務表を貼り付ける」**（設定）で入れる: Excel の表（日付の行、名前の列、マスが番の略称）を貼る → 日付ごとの出勤者と番（`roster.upsert`）。照らせない略称（1 文字・英数字だけの略称を含む）は、その表の中で 1 回だけ選ばせる（対応表の保存は「見直す条件」）。「休」「公休」「明」「有休」「年」「特」「代」「振」「欠」「病」「/」「－」と空欄は休み。日が前の列より小さくなったら翌月（21 日〜20 日の表）。名簿と照らせた職員のマスが全部空欄の日と、今日より前の日は入れない。同じ日を貼り直すと置き換える（表にない職員は変えない）。スポットの「初回」は、これまで出勤が無い人の、表の中の最初の出勤日だけ。
4. 入れたあとの変更は、その日のボードの朝の帯（番を選ぶ・休み・今日来る人を足す）か、貼り直し。勤務表のない日は、いままでどおり先週と同じ番を写す。朝の帯の文は「勤務表どおり（11/6）に並べました」。朝の帯の「初回」は、過去に出勤が無い人なら職種を問わず付けられる。
5. 画像・PDF の勤務表の読み取り（OCR）は作らない（0002）。
6. 等級・評価の項目は持たない（0011 のまま）。

## 理由（お客さん優先の順）

1. 今日のリーダー: PHS の変更・退職・退所がその場で直せる。月初に勤務表を貼れば、毎朝の帯は「勤務表どおり」から始まり、直すのは当日の変更だけになる（原則 3）。
2. 応援・職員: 表から貼る操作に慣れていない人も、欄に入れる形で足せる。
3. 施設長・委員会: 勤務表ソフトの出力をそのまま貼れる（取り込み機能を作らない）。
4. 開発・工程: 新しいイベントは無い（`staff.upsert / staff.remove / resident.upsert / resident.remove / roster.upsert / roster.remove`）。元に戻すは既存のバッチの打ち消し。

## 失うもの・置き換え

| 失うもの | 置き換え | 評価 |
|---|---|---|
| 勤務表の画像・PDF をそのまま読む | Excel の表の貼り付け | 0002 を守る。紙だけの施設は、先週と同じ番を写す今のやり方 |
| 職員の固定の番（早番の人・遅番の人） | 勤務表の貼り付けと、先週の同じ曜日 | 変則の日に古い既定が残らない |

## 見直す条件
