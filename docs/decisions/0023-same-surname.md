# 0023 同じ姓の職員の見分け方（ボード）

- 日付: 2026-11-07
- 状態: 決定。同日に実装
- 置き換える決定: wording.md §3「チップでは名字のみ」を、同じ姓の職員がいるときだけ名を添えるに（0015 の設定の職員一覧と同じ形をボードにも）
- 関連: 0015（1 人ずつの欄。同じ姓が 2 人いれば名を添える）、ループ 12 #4 の持ち越し

## 背景

同じ姓の職員が 2 人いると、ボードのチップ・カード・担当を追加のパネル・トーストで見分けがつかない（「高橋さんの代わりに高橋さんがやった」）。

## 決定

1. ボードで出す職員の名前は、ふだんは名字だけ。同じ姓の職員がほかにいるときだけ、名を添える（「高橋（けんた）」。設定の職員一覧と同じ形）。
2. 添えるのは、チップ・カード・出勤者・職員表示・担当を追加のパネル・業務の詳細・入れ替えとやった人を変えるの文・トースト。純関数 `boardName`（`src/domain/checks.ts`）。
3. 自分の予定（職員の画面）の「一緒に」も同じ考え方でよいが、今回はボードだけ。

## 理由

- 今日のリーダー: 押し間違い（別の高橋さんを付ける）を防ぐ。
- 名を出すのは見分けが要るときだけ。ふだんの短さ（名字のみ）は変えない。

## 見直す条件

- 名が長くカードに収まらない声（そのときは名の頭の文字に縮める）。
