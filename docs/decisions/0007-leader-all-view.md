# 0007 全体（リーダーのスマホ）を誰に出すか・何をそこで決めるか

- 日付: 2026-11-03
- 状態: 決定
- 関連: 0003（画面と押す回数）、0004 §8（クイック操作は2つ）、0006（リーダーの番 `leaderRank`）

## 決定
- ［自分｜全体］は、その日の番に `leaderRank` がある人（リーダーの番の人）に出す。施設がリーダーの番をひとつも決めていなければ、出勤している人全員に出す。欠勤の人には出さない。
- 「＋」の長押し（補助の操作）は作らない。「＋」と「⋯」をすべての行に出し、どちらも1タップで開く。
- 一覧は「これから」を見る道具にする。時刻を過ぎた業務は薄く出し「（時刻を過ぎました）」と書くが、見出しの「担当未定 n件」に数えず「＋」も出さない（完了とは言わない）。開いたら、いまの時間の行へ寄せる。誰も入っていない休憩カードは出さない。
- 欠勤・早退は、時刻で既定を決める（勤務前＝欠勤、勤務中＝いまの時刻で早退）。勤務中でも来ていない人のために、プレビューで［早退｜欠勤（来ていない）］を1タップで選び直せる。判定はその業務日の時刻で行う（夜勤明けの読み替えは使わない）。
- 付き添い・外出で、同じ方の業務は次のように出す。
  - 個別の業務: 付き添いの時間にすっぽり入るものは「中止」に既定でチェック。端だけ重なるものは候補として出し、チェックなし（帰ってから行うことが多い）。
  - 一括の業務: 「対象の方から外す」候補として出し、チェックなし。枠は残す。
- ずらす（⋯）は止めずに決める。ずらした先で担当の人のほかの予定と重なるなら、トーストの文に「◯◯さんは『昼食介助 12:00–13:00』と重なります」と添える。その日の時間割の外（0:00 より前、翌 23:59 より後）へはずらせない。
- 休憩をその人の分だけずらすとき、その人しか入っていない休憩はカードごと動かす。勤務の始まりより前・終わりより後へは動かさない。

## 理由（お客さん優先の順）
1. 今日のリーダーにとって: リーダーは一日で入れ替わる（0006）。朝・夕・夜のリーダーがそれぞれ自分のスマホで全体を見られる必要がある。遅番・夜勤が開いて 7:00 から読むのでは使えない。朝の欠勤の電話は始業の前後に来るので、時刻だけで早退にすると出勤の記録が残ってしまう。
2. 応援・職員にとって: 全体はリーダーだけの画面にし、職員の画面には充足バッジを出さない（CLAUDE.md §3）。
3. 施設長・委員会にとって: 誰がリーダーかは施設の運用（番の `leaderRank`）で決まり、画面の側では決めない。

## 失うもの・置き換え
| 失うもの | 置き換え | 評価 |
|---|---|---|
| 長押しで担当を付ける近道 | 「＋」→「追加」の2タップ | 押す回数の基準（担当の追加 2）を満たす |
| 過ぎた担当未定の件数 | 一覧の行（薄く残る）とボード | 記録の機能は作らない（0001）ので、過ぎた分は数えない |
| 付き添いで重なる業務の自動中止（端だけの重なり） | チェックを入れれば中止できる | 黙って中止にしない方を取る |
