# 0019 見た目の強弱をつける（最初の画面の画面写真・時刻の線を後ろへ・グループの帯・足りない枠を浮かせる）

- 日付: 2026-11-06
- 状態: 決定。同日に実装
- 関連: 0003（ボード）、0010・0017（終わった枠）、0018（最初の画面）、グリル `docs/grills/2026-11-06-design-appeal.md`

## 背景

13 画面を撮って見た。色は紺 1 色と温かい灰色の地に絞れていて、文字の大きさ・角の丸みもそろっている。一方で、最初の画面に製品の姿が無く、ボードは白いカードが同じ重さで並び、現在時刻の線が業務名を横切って取り消し線に見えた。作者の答え: 直す案 A〜E を全部やる。

## 決定

1. 最初の画面に、サンプル施設のボードとスマホの画面写真を置き、ロゴ（時間割の格子に 1 つの枠）を作る。
2. 現在時刻の線はカードの後ろに通す。時刻の札は前に残す。
3. ボードの列の見出しに、グループごとの淡い色の帯（4px）。カードの地は白のまま。
4. 担当未定・担当あと n 人の枠に影を付けて浮かせる。満たしている枠には何も足さない。見守りのレールは控えめに。
5. スマホの「いまの時間の予定」のカードに紺の帯。「全体」の見出しに残る枠を消す。
6. 細いカードの 2 行目は始まりの時刻だけ。

色は状態を示す主役にしない（状態は文字。色は補助）。新しいイベント・機能は無い。

## 見直す条件

- グループの色を施設が選びたい声 → 設定に色を足す。
