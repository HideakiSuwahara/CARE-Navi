# 受け入れ条件と E2E シナリオ

提出（11/8）までに全項目を満たし、提出前にもう一度すべて確かめる（決定記録 0012: 機能凍結はしない）。チェックは `qa-tester` が Playwright で自動化し、手動確認が必要なものは `docs/reviews/` に記録する。画面と押す回数は決定記録 0003 に従う。

**押す回数の基準**: 朝の準備 1（この内容で作る）／担当の追加 2（ドラッグなら 1）／スマホの変更 3 以内（ボタン → 選ぶ → 決定）／元に戻す 1。

## 1. 受け入れ条件（チェックリスト）

### 使い始め（設定）
- [x] はじめて開いた設定画面はボタン2つだけ（「サンプル施設で試す」「自分の施設で始める」）。同期が使える環境では「施設コードで参加」を加えて 3 つ（0009）。
- [x] 「サンプル施設で試す」を押すと、入力なしでボードが開く（架空の「ひまわり苑」）。
- [x] 自分の施設は、施設名＋グループ・利用者の貼り付け・職員の貼り付け（PHS は任意）で登録できる。失敗行は行番号と理由が出る。
- [x] ふだんの設定は、画面の明るさ（0020）、手元画面の利用者名、初回の方の警告、施設コード、データの備え（0014）。

### ボード（時間割と配置）
- [x] 個別（対象1名）・一括（対象複数）・共通（対象なし）・休憩が同じボードに出る。（D1）
- [x] 見守りなど2時間以上の継続業務は列の左のレールに出て、短い業務の幅をつぶさない。（D1）
- [x] 一括業務の対象者一覧を開いて確認できる（人数だけではない）。
- [x] 未充足の枠だけに「担当未定」「担当あと n 人」の文字が出る。充足は無印。休憩にはバッジが付かない。（D1）
- [x] 見出しに「担当未定 n件」「担当あと1人 n件」と、実際の文言ごとの件数が出る。（D1）
- [x] すべてのカードに 44px 以上の「＋」がある。（D1）
- [x] ボード右上に「更新 hh:mm」（時刻のみ）。（D1）
- [x] 端末が暗い設定なら紺の暗い画面。設定の「画面の明るさ」で明るい・暗いを選べ、その端末が覚える。印刷は明るい。暗い画面の全画面で axe（コントラストを含む）の違反 0（`e2e/judge.spec.ts`。決定記録 0020）。
- [x] 終わった印のある枠は灰色の地で「✓ 終わった」。印の無い枠は白のまま。「見るグループ」で選んだグループと共通の列だけになり、読み込み直しても同じ。「横に並べる」［利用者ごと］で、そのグループの方が列に並び、その方の枠が出る（見守り・共通・休憩は出ない。何人かが対象の枠は「n人の枠」の写しで、押すと同じ詳細が開き、地は灰色にしない）。見出しの担当未定は見ているグループの分（単体 5 件、`e2e/board-view.spec.ts`。決定記録 0017）。
- [x] 現在時刻ラインが出る。（D1）
- [x] 右の「きょうの出勤者」に件数・予定時間が出ない（人に数字を付けない）。休みの人には「この人の番の枠 n 件が担当未定」だけ。（D1）
- [x] スマホ幅でボードを開くと、崩れたボードではなく「自分の予定」への案内（1文と1ボタン）が出る。
- [x] 職員チップをカードへドラッグで割当（1操作）。カードの「＋」→「追加」でも同じ結果（2操作）。
- [x] 「＋」のパネルは「問題なし」の人だけを開いて出し、他は「ほかの人（注意 n・勤務外 n）」に畳む。全員に理由が一文付く。
- [x] 重複・勤務外・休憩・条件不一致・初回のみ は警告して許可。二重登録はできない。
- [x] すべての変更がトーストで分かり、「元に戻す」（PC はツールバー、常設）で戻る（10手）。
- [x] カードを押すと詳細（中止・ずらす・担当を外す・対象者）。時刻のドラッグ変更は存在しない。
- [x] ボードの職員表示（横軸［職員］）で重なり・勤務外・休憩・見守りの空きが見える。件数・予定時間は出ない。

### 今日の時間割を作る（ボードの朝）
- [x] その日の時間割が空のとき、ボードの上に「今日の時間割を作る」が出る。
- [x] 先週の同じ曜日の番で出勤者が並び、曜日の業務表が選ばれている。初回・休みは引き継がない。
- [x] 「この内容で作る」1タップで時間割ができ、番に束ねた業務に担当が付く。1回で元に戻せる。
- [x] 介護助手を「休み」にすると、その番の枠が「担当未定」になる。
- [x] 「今日の時間割を作り直す」はボードの ⋯ に置かない（決定記録 0005）。作ったあとの変更はカードの操作とクイック操作で行い、どれも元に戻せる。
- [x] 「今日を業務表として保存」（ボードの ⋯）で時刻・番・必要人数・対象の方が保存される（人は保存されない）。
- [x] 「目標1分」など急かす表示がない。
- [x] 自分の施設は、ボード・自分の予定・見直しが端末の今日で開く。サンプル施設は 11/3 で開く。ボードの「前の日」「次の日」「今日へ」で日を移れる（決定記録 0013）。
- [x] 先週の同じ曜日がないときは、いちばん近い前の日と同じ番で並ぶ。前の日に夜勤だった人は休みで並ぶ。単体テスト `domain.test.ts`。
- [x] 先週、番なしで休みだった人は休みのまま並ぶ（番なしの出勤で「この内容で作る」が押せなくならない）。
- [x] 時間割を作ったあと、右の「＋ 今日来る人を足す」で名前と番を選ぶと、その番の担当が足りない枠に入る。1 回で元に戻せる。
- [x] PC のボードのツールバーから「欠勤・早退」「付き添い・外出」を開ける。決定のあと担当が足りない枠が増えたら、トーストに件数と「＋ から埋められます」が出る。
- [x] ボードを開いたとき、前の画面や前の日の操作のトーストが出ない（元に戻すはツールバーに残る）。

### 自分の予定・業務詳細（スマホ）
- [x] ボードで変えた担当が、別タブ（ローカル）の自分の予定に反映される。
- [x] 同期: 設定で施設コードを発行 → 別端末が参加 → 変更が届く。届かないときは「この端末の内容」と出て動き続ける（決定記録 0009。`e2e/sync.spec.ts` を実際の Supabase で確認。届かないときの動きは単体テスト）。
- [x] 見出しは「いまの時間の予定」。いまの予定がなければ「最初の予定」または「つぎ」を同じ大きさで出す。
- [x] 「実施中」「完了」「済」の語がどこにもない。時刻が過ぎた予定を自動で終わった扱いにしない（濃さも変えない）。薄くなるのは人が付けた「終わった」の印だけ（決定記録 0010。`e2e/acceptance.phone.spec.ts` L45）。
- [x] 0021: ボードの「元に戻すの履歴」で見ている日の操作が新しい順に並び、選んだところまで戻せる（2 件以上は確かめる）。担当を追加のあと「担当がそろっていない次の枠へ」で次の枠のパネルが開く。自分の予定の空き時間に「予定のない時間」と手伝える仕事の名前が出る（札・件数は出ない）。業務の詳細で 2 人の担当を入れ替えられ、1 回で元に戻る（`e2e/judge.spec.ts`）。
- [x] 0022: 業務の詳細の「やった人を変える…」で、担当の人の代わりにやった人を選ぶと担当が替わり「終わった」が付く。担当未定の枠でもやった人を選べる。始まる前の枠には出さない。1 回で元に戻る（`e2e/judge.spec.ts`）。
- [x] 「終わった」の印: きょうの流れの始まった行・業務詳細で 1 タップで付け外しでき（始まる前は一言聞いて 2 回目で付く: 0021）、トーストの「元に戻す」で戻る（戻したあとも一言出る）。先の行・休憩・見守りには出さない。誰が付けたかは画面に出ない（`e2e/done.phone.spec.ts`）。
- [x] 業務詳細で「対象の方」は「お願いすること」「物品」の次、手順より上に出る（決定記録 0010 決定 5）。
- [x] 充足バッジ・「一括」「共通」「ノンコア」の語を職員の画面に出さない。
- [x] 上部に常に「困ったら ◯◯（リーダー）PHS ◯◯◯」。相談先が休憩中なら代わりの人。
- [x] 業務詳細に お願いすること／しないこと・物品・手順・対象の方・困ったら が出る。
- [x] 手元画面の利用者名が設定に従う（既定: 部屋番号＋姓）。ボードはフルネーム。
- [x] 共有端末で名前を選べ、その端末が覚える。

### 全体（リーダーのスマホ）
- [x] 各行に「⋯」（終わった・中止・ずらす・担当を外す）、未充足の行に「＋」が常に出る（長押しは作らない: 決定記録 0007）。
- [x] 見出しに「終わっていない n 件」（自分の勤務が始まってから、終わりの時刻を 15 分過ぎて印の無い行。休憩・中止・見守りは数えない。担当未定とは別）。押すと該当行へ（押すたびに次へ）。行の「終わったら押す」で件数が 1 減り、印の付いた行は文字だけになり、⋯ から外せる（`e2e/done.phone.spec.ts`）。ボードも同じ見出しと、カードの「✓ 終わった」（`e2e/done.spec.ts`）。サンプルの 11/3 は 10:12 に「終わっていない 2件」。
- [x] クイック操作（欠勤・早退／付き添い・外出）と「元に戻す」が画面の下にある（0004 §8: 休憩をずらすは「⋯ → ずらす」）。
- [x] 付き添いは ボタン → 利用者 → 「この内容で決定」の3タップ（既定: 受診の付き添い・今から90分・担当は空き）。
- [x] 付き添いと重なる休憩は外さず、勤務時間内で後ろへずらす。
- [x] 欠勤・早退は ボタン → 職員 → 決定 の3タップ（出勤前は欠勤、勤務中は今の時刻で早退）。

### 業務の見直し・印刷
- [x] 前提「予定時間ベース」「職員の評価には使いません」が常時出る。期間は今週のみ。
- [x] 区分×時間帯の図（色だけに頼らず、数値の表も）、介護助手等の勤務帯、ノンコアの枠一覧（番別・枠別。個人別なし）。
- [x] 枠一覧に判断の言葉（任せられる・要らない）がない。（0004 §8: 「見直す ▾」は作らない）
- [x] 分担表（A4横・日中と夜間の2枚、ボードの ⋯ から）と自分の予定（A4縦）が印刷できる。

### 表現・データ
- [x] 「人手不足」「不足」「未実施」「完了率」「実施中」の語が UI に無い（`npm run check:wording` が通る）。（D1 のボードで確認）
- [x] 実在の利用者・職員・人物の名前を含まない。架空データのみ。
- [x] 業務日と夜勤の MVP 制限が README に明記されている。
- [x] 設定の「追加・変更」で、グループを足すと雛形の番と日課の枠が入り、次の日のボードにその列と枠が出る。名前を変えるとボードの見出しも変わる。所属が残る間は外せない（理由が出る）。番の名前・時刻を直せ、入れてある勤務表の時刻は変わらない。施設の名前を直せる。どれも元に戻せる（単体 5 件、`e2e/setup.spec.ts`。決定記録 0016）。
- [x] グループを足すとき種類［ユニット｜フロア］を選べ（名前から推した既定）、名前を変えても種類は変わらない。外せない理由はその行に出て、利用者の画面・職員の欄へのリンクが付く。職員の所属を職員の欄で直せる。外した番が過去の勤務表に残っても、先週・前の日の写しではその人を休みで並べる。夜勤の終わりを 9:00 と入れても翌9:00 として受け、そう知らせる。開く・閉じる・足す・外すのあとフォーカスが迷子にならない（単体 4 件、`e2e/setup.spec.ts`。ループ 13）。
- [x] 設定の「職員」で、1 人ずつ足す（名前・職種・担当条件・PHS）・名前を押して直す・退職にできる。退職は今日以降の担当と出勤を外し（押すのは最後に出た日の翌日と案内）、元に戻すで全部戻る。同じ名前は足せない（`e2e/setup.spec.ts`。決定記録 0015）。
- [x] 設定の「月の勤務表を貼り付ける」に表を貼ると、日付ごとの出勤者と番が入り、ボードの朝の帯がその番で並ぶ。照らせない略称（1 文字・英数字だけを含む）は選べる。名簿と照らせない名前は入れずに知らせる。21 日〜20 日の表は翌月に送る。空欄だけの日と今日より前の日は入れない。スポットの初回は表の中の最初の出勤日だけ。同じ日を貼り直すと置き換わり、元に戻せる（単体 7 件、`e2e/setup.spec.ts`。決定記録 0015）。
- [x] 利用者の画面の「1 人ずつ足す・直す」で、足す・直す・退所ができる。退所は今日以降の枠の対象から外れ（過去は履歴として残る）、元に戻すで対象にも戻る（`e2e/residents.spec.ts`。決定記録 0015）。
- [x] 設定の「職員」で、職員ごとに条件を 1 タップで付け外しでき、ボードの候補の理由（「条件『…』を満たしていません」）に効く。元に戻せる（`e2e/setup.spec.ts`）。等級・評価の項目は作らない（決定記録 0011）。
- [x] 再読み込み時の保存方式（ブラウザ内保存・サンプルに戻す）が README に明記され、動く。端末間の同期（施設コード）は決定記録 0009 で作った。認証・権限は本番の要件として README に書く。
- [x] 製品内に外部AIの呼び出しが無い（依存と環境変数にも無い）。

## 2. E2E シナリオ（Playwright）

### S0 ボードの表示（D1、`e2e/board.spec.ts`）
1. `/board?now=10:12` を開く（保存を消してから）。
2. 東フロア・さくらユニット・共通の列に業務が並ぶ。
3. 「担当未定 n件」「担当あと1人 n件」が出て、休憩カードにはバッジがない。
4. 出勤者に件数・予定時間がない。禁止語がない。すべてのカードに 44px の「＋」。現在時刻ライン「10:12」。

### S1 担当あと1人を埋める
1. 設定で「サンプル施設で試す」→ ボード。
2. 「入浴介助 10:30」に「担当あと1人」が出ている。
3. パレットの人をカードへドラッグ（1操作）、またはカードの「＋」→「追加」（2操作）。
4. バッジが消え、トースト「◯◯さんを 入浴介助 10:30 に入れました」。
5. 「元に戻す」でバッジが戻る。

### S2 今日の時間割を作る
1. 時間割が空の日（例: 先週の同じ曜日に出勤者がある火曜）のボードを開く。
2. 「今日の時間割を作る」に先週の番で出勤者が並び、業務表「入浴日」が選ばれている。
3. 「この内容で作る」1タップ。
4. 見出しに「担当未定 n件」「担当あと1人 n件」。該当カードへ寄る。
5. トーストの「元に戻す」で空に戻る。

### S3 付き添い・外出（スマホ、3タップ）
1. スマホ幅で自分の予定 →［全体］。
2. 「付き添い・外出」→ 利用者（田中様）を選ぶ。
3. プレビューに「追加」と結果の「担当未定」が出る。担当を付けた場合は「外す（重なるため）」と「休憩をずらす」が出る。
4. 「この内容で決定」→ 一覧に受診の付き添いが現れる。
5. 「元に戻す」で全行が戻る。

### S4 スマホへの反映
1. タブA: ボード。タブB: 自分の予定（佐藤）。
2. タブA で佐藤を「レク準備 14:00」に割り当てる。
3. タブB の「きょうの流れ」に 14:00 レク準備 が 2 秒以内に現れる。
同期環境（環境変数あり）では、タブB を別端末（施設コードで参加）に置き換えて同じ確認を行う（`e2e/sync.spec.ts`。PC で発行 → スマホが参加 → PC の担当の追加がスマホに届く）。

### S5 業務詳細（初回の方）
1. 共有端末で「加藤」を選ぶ（12:50 の状態）。
2. 先頭に「最初の予定」として到着・案内と口腔ケアが、お願いすること・物品を開いた状態で出る。
3. 上部に「困ったら」と、リーダーが休憩中なら代わりの人。対象者は「部屋番号＋姓」。
4. 「実施」「完了」のボタンや語が無い（「終わったら押す」の印だけ。決定記録 0010）。

### S6 印刷
1. ボードの職員表示 →「⋯ → 分担表を印刷」→ A4 横（日中・夜間の2枚。`page.emulateMedia({media:'print'})` でレイアウト確認）。
2. 自分の予定 →「⋯ → 印刷」→ A4 縦 1 枚。

### S7 表現チェック
- 全画面のテキストに禁止語が無いことを `check:wording` と E2E の本文検査で確認。

## 3. 手動確認（レビューループで実施）
- 3ペルソナ（新人・初回の応援・リーダー）の初見シナリオを `ux-first-timer` が実機幅で実施し、押した回数と迷った箇所を `docs/reviews/` に残す。
- 実在のリーダー 1〜3 人の 15 分試用（docs/usability-script.md）。

## S-R 利用者と24時間シート（決定記録 0004）

- [x] 名簿を貼り付けただけで、全員が標準どおりとして時間割に入る（追加の入力なし）。
- [x] 一覧（利用者×日課）で、標準と違うマスだけが文字で目立つ（「—」／太字の時刻／「なし」）。
- [x] マスを押して時刻を変えると、次に時間割を作ったとき、枠の中なら一括の枠のまま（対象者一覧に時刻）、枠の外なら別の枠になる。
