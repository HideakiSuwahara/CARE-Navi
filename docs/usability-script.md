# 15分の試用台本（実在のリーダー向け）

目的: 初めて見る人が、サンプル施設で「担当あと1人」を解消するまでの時間と、迷った箇所を知る。効果の証明ではない。結果は「初見試用の実測（n=◯）」としてだけ使う。

## 0. 準備（進行役）
- サンプル施設のURL（ログイン不要）。PC またはタブレットと、できればスマホ。
- 2 台で試すとき（同期）: PC の設定で「サンプル施設で試す」→「この施設を同期する」を押し、出た QR をスマホで読む（決定記録 0009）。1 台なら、スマホ幅の窓を横に並べる（同じブラウザの別タブで即時に揃う）。
- 画面の時刻を固定したいとき（課題C・D を 10:12 の状態で見せる）は URL に `?now=10:12` を付ける。このとき見出しの「更新 hh:mm」は実際に変えた時刻のままなので、試用者には「更新は本当の時計」と一言添える。
- 記録用紙（下の表）。ストップウォッチ（スマホで可）。
- 進行役は操作を教えない。質問には「どう思いますか？」と返す。

## 1. 同意（1分）
口頭で次を伝え、了解を得る。
- 試しているのは道具であって、あなたではないこと。
- 画面の操作時間と、迷った箇所をメモすること。録画・録音はしない。
- 感想を引用する場合は、名前も施設名も出さず、事前に本人に文面を見せて了解を得ること。了解がなければ使わない。
- いつでもやめられること。

## 2. 導入（1分）
読み上げる: 「介護現場の一日の業務を時間割にして、そこに人を当てる道具です。架空の施設『ひまわり苑』のデータが入っています。記録はしません。AIも使っていません。いまから4つのことをお願いします。」

## 3. 課題（10分。課題D は時間があれば）

### 課題A: 担当あと1人を埋める（目安 2操作。ドラッグなら1）
「ボードの中で、人が足りていない枠を見つけて、誰かを入れてください。」
- 計測: 開始→バッジが消えるまでの秒数、操作数、迷った箇所。
- 観察: バッジの文言を読んだか／D&D かタップか／候補の理由を読んだか／元に戻すに気づいたか。

### 課題B: 今日の時間割を作る（目安 渡辺さんを休みにして1回＋作る1回）
「今日の時間割を作ってください。渡辺さんは休みです。」
- 計測: 時間割ができるまでの操作数と秒数（急かさない。時間は参考）。
- 観察: 先週の番で並んでいることに気づいたか／「番」の意味が伝わったか／「休み」にしたあとの「担当未定」を理解したか（「これは何だと思いますか？」）。

### 課題C: スマホで自分の予定を見る（目安 0操作）
スマホ（または狭い窓）で: 「あなたが佐藤さんだとして、いま何をする時間か、次は何か、見てください。業務を開いて、困ったときに誰に聞くか探してください。」
- 観察: 「いまの時間の予定」の見出しをどう受け取ったか／相談先にたどり着いたか／対象者の表示（部屋番号＋姓）をどう思ったか。

### 課題D: スマホで付き添いを足す（目安 3タップ。リーダーの番の人で）
スマホで佐藤さんを選び、画面下の［全体］を開く: 「田中様が急に受診になりました。付き添いを入れてください。入れたら、元に戻してください。」
- 計測: 「付き添い・外出」を押してから「この内容で決定」までのタップ数と秒数。元に戻すまでのタップ数。
- 観察: 「こう変わります」の行を読んだか／担当を決めたか決めなかったか／「元に戻す」の場所にすぐ気づいたか／PC のボードに同時に出たことに気づいたか（2 台のとき）。

## 4. 聞くこと（3分）
順番に。答えはそのまま書き取る（要約しない）。
1. 「明日の朝、これを開きますか。開くとしたら何時ですか。」
2. 「10時に受診が入って職員が1人抜けたとき、これを触りますか。触るならどの画面ですか。」
3. 「『担当未定』という言葉は、どう聞こえましたか。」「『番』『業務表』という言葉は分かりましたか。」
4. 「応援やスポットの人に、このスマホ画面を見せても大丈夫だと思いますか。何が足りませんか。」
5. 「使わないとしたら、理由は何ですか。」

## 5. 記録用紙

| 項目 | 記入 |
|---|---|
| 日付・場所・端末 | |
| 役職（施設名・個人名は書かない） | 例: 従来型フロアの日勤リーダー、経験◯年 |
| 課題A 秒数／操作数／迷った箇所 | |
| 課題B 秒数／迷った箇所 | |
| 課題C 到達できたか／迷った箇所 | |
| 課題D タップ数／秒数／迷った箇所 | |
| 質問1〜5 の回答（原文） | |

## 6. 結果の使い方
- 迷った箇所は `docs/reviews/` に「試用 n=◯」として記録し、修正の優先順位に使う。
- 動画・提出文では「初見試用（n=◯）で課題Aの中央値 ◯秒」のように、測ったことだけを書く。
- 引用は了解を得たものだけ。創作しない。足りなければ引用なしで出す。
