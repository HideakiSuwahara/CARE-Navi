# 進み具合（全体工程）

区切りのたびに更新する。`npm run progress` で合計を出し、Claude Code の作業が終わるたび（Stop フック）にも「全体工程 約 n%」を表示する。

- 重みは工程の大きさの見積もり（合計 100）。進み（%）はその工程の中での見積もり。
- 受け入れ条件のチェック数は参考として別に出す（受け入れ確認を回すまでは、作ってあっても未チェックの項目がある）。
